# ADR-004: 分镜导出复用视频合成任务队列

## 状态
Accepted

## 日期
2026-09-24

## 背景（Context）
画布已有视频拼接任务队列、取消、恢复、进度和成片存储能力；分镜板还需要绝对时间轴叠字、空白镜头和多音轨。

## 问题（Problem）
如何让分镜导出获得可靠异步执行能力，同时保持现有画布拼接行为稳定。

## 决策（Decision）
在现有视频合成任务中增加分镜导出类型和不可变输入快照，复用队列、状态与媒体存储；独立实现分镜时间轴的 FFmpeg 渲染分支。

## 方案比较（Alternatives）
- 新建独立任务系统：隔离清晰，但重复队列、恢复和取消机制。
- 在浏览器导出：依赖浏览器会话，长视频内存与跨域问题较多。

## 原因（Rationale）
沿用已有任务生命周期，增量改动较少；渲染逻辑独立可避免改变画布拼接效果。

## 影响（Consequences）
### 正面影响
- 分镜导出具备现有的任务恢复与取消能力。
### 负面影响
- 视频合成任务表同时承载两类任务，需要明确类型分支。
### 风险
- FFmpeg 字体、滤镜与媒体时间精度需要专门验证。

## 后续行动（Action Items）
- 增加导出接口、时间轴渲染器和相关验收用例。
