# Switch themes

The theme preference belongs to each user. It needs no administrator action and does not affect other members.

## How to switch

Click the theme button at the bottom of the compact sidebar (the sun and moon icon) and pick a mode:

- **System**: Follow the operating system's light or dark setting; the menu shows which theme is currently active.
- **Light**
- **Dark**
- **Purple**

On mobile, open the navigation drawer from the top-left menu and use the "Theme mode" row instead.

## Where it is stored

The preference is stored in your browser (both local storage and a cookie), so it survives a refresh or a new tab. Another browser or device starts from the default.

## Change language

Select **简体中文** or **English** from the language button at the bottom of the sidebar. The mobile navigation, canvas toolbar, sign-in pages and documentation header offer the same control.

Your first visit follows your browser language preferences. Simplified Chinese is used when no supported language matches. A manual selection is saved in a browser cookie for one year and survives a refresh.

Changing language preserves your input, canvas, sign-in session and running generation tasks. Interface text, controls and system messages change language. Your content, announcements, artwork, prompts and model output retain their original text. Switching documentation language keeps the current article.
