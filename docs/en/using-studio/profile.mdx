# Personal information

The personal information control in the top-right shows the current avatar, nickname, and credit balance.

## Available actions

- View the current account and credit balance.
- Open the profile page to change a nickname or avatar.
- View credit history and redemption options.
- Sign out of the current session.

The balance is refreshed from the server after sign-in so an old browser snapshot is not shown.
