# 项目介绍

Novanova Studio 是一个由 AI Agent 驱动的视觉创作工作台，把图片、视频、无限画布、提示词和资产管理放在同一条创作链路中。

## 核心能力

- **对话式创作**：用自然语言描述目标，Agent 根据上下文选择工具和工作流。
- **图片与视频生成**：支持多模型渠道、参考素材和异步任务进度。
- **无限画布**：把灵感、素材、生成结果和任务关系组织在一个可编辑空间。
- **可复用资产**：生成记录、提示词和上传素材可以保存并在后续创作中继续使用。

## 典型工作流

1. 配置模型渠道和对象存储。
2. 在图片、视频或画布中输入创作目标。
3. Agent 询问缺少的参数并提交异步任务。
4. 查看结果，继续迭代，或保存到资产库和画布。
5. 使用同一上下文完成下一轮创作。

## 系统架构

系统自上而下分为五层：浏览器工作台、接入层、前端服务、后端服务、数据与外部依赖。浏览器只访问同源的 `/api/v1/**`，AI 渠道密钥与对象存储凭证都保存在服务端，不会下发到浏览器。

![Novanova Studio 系统架构](/docs-assets/architecture.zh-cn.svg)

| 层 | 组成 | 职责 |
| --- | --- | --- |
| 浏览器工作台 | Next.js 16 App Router、React 19、Ant Design 6、Tailwind、Zustand、React Flow | 图片、视频、无限画布、资产、提示词库与管理后台的交互界面 |
| 接入层 | Nginx 1.27 | TLS 终止与反向代理：`/api/*` 转发到服务端并关闭缓冲以支持 SSE 实时推送，其余请求转发到前端 `:5550` |
| 前端服务 | Next.js standalone（Node.js 22） | 页面渲染、`/docs` 文档门户与静态资源 |
| 后端服务 | Java 21、Spring Boot 3.5、Spring WebFlux、AgentScope Java、Fastjson2、R2DBC | 响应式 API、Agent 编排与工具调用、AI 任务调度与轮询、鉴权、业务服务 |
| 数据与外部依赖 | PostgreSQL 17 + Flyway、Redis 8.6 + Stream、对象存储（COS / OSS / Kodo）、模型渠道 | 用户与创作数据持久化、异步任务分发与恢复、素材与生成结果存储、模型推理调用 |

### 一次生成请求的链路

1. 浏览器在工作台或画布中提交创作目标。
2. Nginx 把 `/api/v1/**` 转发到服务端，SSE 响应保持不缓冲。
3. 服务端的 Agent 结合上下文选择工具（图片、视频、画布、分镜），并补齐缺失的参数。
4. 任务写入 PostgreSQL 并通过 Redis Stream 分发；上游模型渠道多为异步任务接口，服务端按统一的轮询间隔查询进度。
5. 结果回写数据库与对象存储，浏览器通过 SSE 或轮询获取结果，并可直接落到画布或资产库。

Docker 部署会把 PostgreSQL、Redis、Nginx、前端与后端一起启动，具体步骤见[使用 Docker 启动](./docker-start)；接口与数据库表设计见仓库中的 `docs-api/` 目录。
