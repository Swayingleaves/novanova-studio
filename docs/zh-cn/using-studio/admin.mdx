# 管理后台

管理员登录后，左侧导航「设置」分组里会出现「管理后台」入口（`/admin/system`），用户菜单里也会多一项「系统管理」。该入口对普通用户不可见；直接访问地址会看到「需要管理员权限 / 当前账号无法访问系统管理。」，后端接口同样会拒绝并返回「权限不足」。

页面由九个标签页组成，下面按顺序说明。

## 用户管理

- 顶部统计：总用户数、本月用户增量、今日用户增量。
- 表格列：ID、用户（昵称·邮箱）、角色、状态、可用积分、密码锁定、创建时间、操作。
- 可执行操作：新增用户（邮箱、密码至少 8 位、昵称、角色）、修改角色（普通用户 / 管理员）、调整积分、解除锁定、禁用 / 启用。
- **调整积分**：填写正负积分值与必填的调整原因（不超过 200 字），原因会写进用户的积分流水，类型为管理员调整。
- 限制：不能禁用当前登录的管理员（提示「不能禁用当前登录管理员」），也不能移除自己的管理员角色（提示「不能移除当前登录管理员角色」）；被禁用的账号登录时会收到「账号已被禁用」。
- 支持按关键字、用户 ID、角色、状态和创建时间范围筛选，每页 20 条。

## 积分消耗

- 筛选：用户、日期范围（今日 / 近 7 天 / 近 30 天 / 本月）、类型（全部 / 生图 / 生视频）、趋势按日或按月。
- 图表：生图与生视频占比、模型占比、消耗趋势。
- 明细列：用户、生成类型、模型、来源、消耗积分、时间。

## 卡密管理

- **生成卡密**：填「数量」（1～1000）与「单卡积分」（不小于 1）后点「生成」，生成结果弹窗里可以「一键复制全部卡密」。目前没有有效期设置。
- 批次表：批次、单卡积分、库存、创建管理员、创建时间。
- 库存表：卡密（默认脱敏，可切换「查看完整卡密」）、批次、积分、状态（未兑换 / 已兑换）、兑换用户、兑换时间、积分流水。
- 支持按批次、状态、卡密或末四位、兑换用户 / 邮箱筛选。用户侧在「兑换积分」页输入 20 位卡密即可到账。

## 消息管理（系统公告）

- 表格列：标题、内容、优先级、状态（已发布 / 草稿）、发布时间、创建时间、操作。
- 新建只填标题（必填）和内容；编辑可改标题与内容；只有草稿能「发布」，确认文案是「发布后所有用户将看到此公告，确定发布？」。
- 公告通过客户端轮询下发，用户侧最长约 30 秒可见，见[系统公告](./announcements)。

## 提示词库

维护提示词记录的标题、内容、分类、标签、预览内容、来源 URL、排序与状态，支持搜索、分类筛选与启停。详见[提示词库](./prompt-library)。

## 风格管理

图片与视频的生成风格。字段为名称、分类、封面（必填）、风格提示词、生成类型（图片 / 视频）、排序与状态；卡片网格支持多选批量删除。停用文案是「停用后新生成不能选择该风格，历史快照不受影响。」。

## 技能管理

面向对话的技能。表格列为技能名称、类型（图片 / 视频 / 画布设定图）、简介、默认比例、状态、排序；表单字段有名称、类型、简介、封面、默认比例（16:9 / 9:16 / 1:1 / 4:3 / 3:4）、流程提示词、排序与状态。

- 「流程提示词」里的 `workflow: first-last-frame` 这类标记由服务端解析成视频工作流，只有已注册的工作流才会生效；效果见[视频创作](./video-generation)。
- 停用后用户不能继续选择该技能（确认文案「停用后用户不能继续选择该技能。」）。

## 首页展示

管理首页的精选作品墙：预览、标题、分类、创作者、媒体、入口、排序、状态、更新时间、操作，支持多选批量删除。字段包括标题、说明、分类、创作者、媒体类型与地址、缩略图、跳转目标（图片 / 视频 / 画布 / 资产）、跳转路径、提示词内容、排序与状态。列表为空时首页会使用内置示例。

## 接口记录

排查后端问题最有用的一页。

- 列：接口（方法 + 路径）、客户端 IP、用户 ID、状态码、是否成功、错误内容、耗时（毫秒）、时间。
- 筛选：关键字（IP、接口地址、用户 ID）、结果（成功 / 错误），每页可切 10 / 20 / 50 / 100 条，列宽可拖拽。
- 详情抽屉里能看到方法、地址、IP、用户 ID、状态码、是否成功、耗时、时间、**请求体**与**错误内容**（不记录响应体）。
- 日志保留 30 天，每天凌晨 3 点清理更早的记录。

## 维护建议

- 对象存储配置完先做一次测试连接，渠道可以用「拉取模型」验证密钥是否有效，确认无误再设为默认。
- 调整积分、禁用用户这类操作用户会立刻感知，建议同步发一条系统公告说明。
- 各项配置字段的完整含义见[系统配置](./system-configuration)。
