# 剧本创作

> **PRO 企业版功能。** 左侧导航中「剧本创作」带PRO 角标，仅在企业版授权下可用。

剧本创作负责一件事：把一个创意变成**可持续反复修改的结构化剧本**。所有内容按「概览 → 大纲 → 人物与世界观 → 分集与场次」分层存放，任何一次修改都不会破坏其他部分。漫剧创作里的镜头、视觉资产与媒体制作不在这里完成，但会共用同一份剧本数据。

## 两种上手方式

| 方式 | 入口 |适合谁|
| --- | --- | --- |
| 新建剧本 | 项目库右上「新建剧本」 | 已有创意或想法，从零搭结构 |
| 上传剧本 / 小说 | 项目库右上「上传剧本/小说」 | 已有小说或剧本原文，需要AI 提炼与改编 |

**新建剧本**：填写项目名称、创建方式（`空白项目` 或内置模板）、内容形式、一句话创意（可选）后点「创建并进入」。内置模板覆盖漫剧、真人短剧、动画、广告、音乐视频等16 种类型，选模板时会自动带出对应的内容形式。

**上传剧本 / 小说**：支持导入类型「小说」或「剧本」，原文件支持 TXT、DOCX、DOC，单文件不超过 50 MB；TXT 可指定编码（`UTF-8` 默认 / `GB18030` 简体中文旧编码）。上传后只保存原文与章节结构，**不会**自动生成人物、分集或正式场次，结构可以在「原文」页人工校对。

## 项目库

项目库卡片展示项目名、内容形式、题材、创作阶段、一句话创意、进度（`已完成集数 / 目标集数` + 完成率）与最近修改时间。

-顶部可按「内容形式」（漫剧 / 真人短剧 / 动画 / 广告 / 宣传片 / 音乐视频 / 故事短片）和「创作阶段」（构思中 / 大纲中 / 编写中 / 已完成 / 已进入制作）筛选，搜索框支持项目名或一句话创意。
- 勾选多个项目后可以「删除所选（N）」。项目会被移入软删除状态，关联剧本内容不会立即物理清除。

## 保存机制（务必先读）

剧本工作台**没有自动保存**。顶栏的「保存」按钮只有在内容变化后才可点击，保存状态有六种：`尚未修改 / 有未保存修改 / 保存中 / 已保存 / 保存失败 / 版本冲突`。

- 切换区块时有未保存修改会弹窗，可「保存并继续」或「放弃并继续」。
- 关闭标签页或刷新走浏览器原生提示；点击站内链接会先拦截确认。
- 保存失败时横幅提示「保存失败，编辑内容仍保留在本地页面中。」并提供「重试保存」。
- 版本冲突时提示云端已被其他页面更新，可复制重要内容后「重载云端版本」。
- 「放弃并继续」会**真的丢弃**本地改动并重载云端内容。

以下操作都有「先保存」的前置校验，遇到时请先点保存：调用 AI、发起小说改编或正文生成、创建/恢复版本、删除人物或分集、进入漫剧创作。

## 工作台分区

左侧目录分两组：

| 分组 | 目录项 |
| --- | --- |
| 剧本 | 故事概览、故事大纲、人物设定、世界观与地点、分集剧本、版本记录 |
| 小说 | 原文、故事知识库、小说改编 |

底部还有「分集与场次」快捷目录：展开某集可直接查看场次，`+` 按钮为该集新增场次，虚线按钮「新增分集」在末尾追加分集。目录里选中分集或场次时，右侧 AI 面板的「当前目标」会同步切换。

### 故事概览

先把故事目标、主要冲突和最终方向写清楚。字段包括项目名称、内容形式、题材、目标集数、目标总时长，以及一句话创意、故事梗概、故事主题、主线剧情、主要冲突、结局方向、叙事风格。

**一句话创意与故事梗概至少填一项**，否则无法生成候选故事方向或故事大纲。

### 故事大纲

默认是阅读版式：左侧目录、右侧纸张式排版，包含眉标、一句话创意、题材/目标集数/结构段数量、故事人物小节（角色定位、身份·年龄·职业、目标）与各章的关键事件卡片。

切到「编辑」后可按幕结构、主线、支线、人物成长线四类组织结构段，每个结构段下可添加关键事件，事件类型为剧情 / 冲突 / 悬念 / 反转 / 高潮 / 结局，并可关联到具体分集与场次。

关联场次前需要先在「分集剧本」中打开该分集，以加载它的场次列表。

### 人物设定

卡片网格展示，头部是姓名首字，正文显示姓名、角色定位、`年龄 · 身份 · 职业` 与性格摘要。点击卡片打开编辑弹窗，字段分三组：

- **基本信息**：人物姓名（必填）、角色定位、年龄、身份、职业
- **性格与动机**：性格、价值观、外在目标、内在欲望、恐惧、核心动机
- **外貌与经历**：外貌文字描述、习惯、语言特点、背景经历、人物弧光

工具栏支持「本页全选」、批量删除与「添加人物」。删除前会提示：关联关系会一起删除，人物若被场次或对白引用，服务端会拒绝删除。

### 世界观与地点

顶部先填时代、地域、社会背景与整体基调，然后分两个页签：

- **世界规则**：按规则 / 组织 / 势力 / 等级 / 限制 / 历史事件六类再分子页签，每类独立卡片网格。
- **场景地点**：记录地点名称、空间用途、叙事作用、默认时间、天气、空间氛围、关键物件与主要事件。

删除被场次引用的地点时，场次上的地点会变成空值。

### 分集剧本

横向卡片轨道：封面卡展示集号、分集标题、分集梗概、场次数、完成状态与目标时长；每个场次一张卡，展示`第 N 场`、场次标题、`地点 · 时间 · 内景/外景`，正文按动作 / 对白 / 旁白 / 转场四种块排版，对白会显示说话人。改编生成的块额外标注「改编创作」。

支持左右箭头、滑块、滚轮与 `←/→`、`PageUp/PageDown`、`Home/End` 翻页。

每张卡上有三个快捷操作：编辑、AI、删除。编辑弹窗里可以设置分集标题、完成状态（规划中 / 草稿 / 已完成）、目标时长，以及每个场次的地点、内外景、发生时间、出场人物、场次目标、动作概述、转场说明、与前后场次的关系，并逐块编辑正文，支持「AI 优化场次」「AI 优化正文块」。

## 原文（小说项目）

上传原文后在这里校对章节与场次结构。状态标签有`排队中 / 解析中 / 已完成 / 解析失败`，解析按「读取原文件 → 写入章节与片段 → 已完成」推进。

校对工作区左侧是章节树（父为章节、子为场次），待校对项带金色「待校对」标签；右侧可以对任一段做：

- 改标题（点「保存标题」）
- **拆分**：开启拆分模式后，正文每行行首出现「拆分」按钮，把该行起的正文划为新结构段
- **与上一段合并 / 与下一段合并**：两段正文按原顺序拼接，原文件不变

正文每行左侧显示起始偏移，点击证据可自动滚动并高亮。段落过长时只显示前 600 行且不超过 20000 字符，拆分位置只能在可见范围内选择。

**「确认结构」是启动故事知识库分析的前置条件**，确认后才能进入知识库。TXT 解析失败时可以直接「切换为 GB18030 并重试」。

## 故事知识库

基于原文做 AI 结构化提取，把长文本变成可核对、可编辑的知识条目。

### 分析流程

1. 选择文本模型。
2. 选择分析范围：默认全书，也可以勾选章节或场次做局部重分析。
3. 点「报价并分析」，弹窗展示模型、范围、计费字数、价格档位、**预扣积分**与批次数量。计费说明写明：按原文字数档位预扣，取消时仅扣成功完成的初始批次（退款向下取整），已完成内容保留，模型最终失败全额退款，**人工确认或修改过的条目不会被覆盖**。
4. 任务按「分批提取 → 故事线归纳 → 已完成」推进，状态有`排队中 / 分析中 / 已中断，可续跑 / 已完成 / 部分完成 / 失败，已退款 / 已取消，按批次结算`。
5. 中断的任务可以「续跑」；也可以「取消」，取消只按成功批次结算。

需要注意：分析**按本次所选范围重新计费**，不做「跳过已分析章节」的增量处理。已有条目不会重复创建——未锁定条目会被覆盖更新，已确认或已锁定的条目只会收到待审建议。

### 六个页签

`人物 / 地点 / 关系 / 事件 / 故事线 / 时间线`（时间线复用事件数据，只是排序方式不同，可切换「叙事顺序」与「故事时间」）。

每个条目有状态：`待确认 / 已确认 / 已拒绝`，另有「已锁定」标记。**确认条目会把该条目标记为锁定**，之后重新分析产生的新建议不会自动写入，需要你手动「并入」或「拒绝」。

### 证据

每条条目底部显示证据条数，点「查看原文」跳转到原文对应位置并高亮。条目详情抽屉里列出全部原文证据（起始偏移 + 引文），可点击跳转。证据只能由分析生成，只读；合并与拆分条目时可以勾选分配。

### 批量确认

工具栏提供「本页待确认全选」「批量确认（N）」「全量确认」。确认后条目会锁定，待审建议会合并到对应条目；全量确认的范围是当前分类下所有待确认条目，不受分页、搜索与状态筛选影响。

其他操作：新建条目、别名合并与拆分、把故事知识库里已确认的人物/地点事实关联到漫剧视觉资产。

## 小说智能改编

针对已导入原文的项目，左侧目录「小说改编」进入。副标题写明：分批提炼全书素材、归纳统一策略，确认集数后固定分集身份并逐集生成正文；**分镜、视觉资产和媒体制作继续在漫剧工作台完成**。

### 改编设置

先选改编形式、单集时长（秒）、叙事节奏（舒缓 / 均衡 / 紧凑）、改编程度（忠实 / 均衡 / 大胆）与文本模型，然后点「启动全书改编」。参数在任务启动后即定格，只能在未开始或已结束时调整。

启动前会弹报价确认：输入范围为全部已确认故事事实，本次先执行「素材提炼 → 全书策略」然后暂停等待确认集数，并展示预计调用次数与本阶段预扣积分。

### 九步流水线

`改编设置 → 素材提炼 → 全书策略 → 确认集数 → 概览与大纲 → 人物与地点 → 取舍与逐集规划 → 应用替换 → 分集正文`

流水线有两个必须人工确认的停点：

- **确认集数**：策略生成后停住，由你输入最终集数（不能小于故事阶段数）。服务端按各阶段建议比例用最大余数法分配配额，一次性固定全部分集的标识与集号，集号连续 1 → N，且**一旦分配就不再变化**，要调整只能重新发起改编。
- **应用替换**：统一规划生成后暂停，展示待审草稿数量。点「应用并继续」后在一个事务里把概览、大纲、人物地点设定与分集规划写入正式项目，替换同名内容并保存修改前版本。弹窗明确说明：分镜、视觉资产与媒体保留并登记影响，不会被删除；应用失败不会留下半套内容。

### 批量生成分集正文

按已固定的分集逐集生成场次、动作、对白与旁白。两种模式：

- **生成并直接写入正式剧本（推荐）**：每集成功后立即合并进正式剧本，发起前会保存修改前版本。
- **只生成待审草稿**：产出暂存为待审草稿，需要在「AI 剧本助手」里逐集预览并确认应用。

支持快捷选择「全部 / 全部不勾选 / 只选未完成」，一次可以排队上百集；失败或取消后点「从缺失分集继续」只重做未完成的分集，不重复扣费。

## AI 剧本助手

在分集剧本、故事概览、故事大纲、人物设定、世界观与地点这五个创作区块以右侧栏常驻。版本记录、原文、故事知识库、小说改编没有 AI 动作，不显示助手，也不占这一栏的宽度。窗口宽度不足 `xl` 时右侧栏隐藏，改用顶栏「AI」按钮或区块自带的 AI 按钮以抽屉打开。

选动作、模型与目标，填补充要求后点「生成待确认草稿」。面板会显示「当前目标」与「预计积分」。常见动作包括生成候选故事方向、生成故事大纲、生成人物与关系、生成世界观与地点、生成分集规划、生成单集场次与正文，以及润色 / 扩写 / 精简 / 改写 / 口语化 / 对白优化 / 冲突强化 / 悬念优化 / 反转优化 / 动机优化 / 情绪优化 / 高潮优化 / 节奏优化 / 风格优化。

**AI 结果一律先落为待确认草稿**，在「待确认草稿」列表里点「预览差异」查看逐字段差异（`新增 N` / `更新 N`），需要时可展开「高级编辑（原始 JSON）」左右对照修改，再点「确认应用」。草稿状态为 `待确认` 或 `已过期`；项目内容变化后旧草稿会标记过期，不能覆盖当前内容。

前置校验会明确告诉你缺什么，例如「请先在故事概览中填写一句话创意或故事梗概」「请先完成故事大纲」「请先保存当前剧本修改」「请先选择单集、场次或正文块作为AI目标」。

## 版本记录

普通保存不产生历史版本；应用 AI 草稿前会自动保留修改前快照。时间轴上每条显示版本名称、来源（`AI修改前` / `手动`）、修订号、时间与变更说明。

- 「创建版本」可手动创建命名版本（如「第一幕定稿」）并写修改说明。
- 「恢复」不会自动保存当前内容，需要保留现状请先手动创建命名版本。
- 「结构对比」逐区块比较版本与当前内容，可比较区块包括：故事概览、故事大纲、关键事件、人物设定、人物关系、世界观、世界规则、场景地点、分集规划、分集正文。分集正文按需加载，只比较结构化设定与分集摘要。

## 进入漫剧创作

顶栏「进入漫剧创作」会先强制保存，再弹「进入漫剧创作前检查」，逐项列出：故事梗概、分集结构、可用剧本正文、场次生产信息、主要人物、场景地点、待确认 AI 草稿，状态为 `已具备 / 缺失 / 建议补充`。

有缺失项时可以「返回补充」，也可以「忽略缺失并继续」——进入制作只标记当前项目，**不会复制内容，也不会扣除积分**。

## 积分与限制

- 所有 AI 动作（知识库分析、小说改编、分集正文生成、AI 剧本助手）都按所选文本模型计费，执行前展示预扣积分，执行中按成功单元结算，失败或取消时未完成部分退回。
- 未配置模型价格时会提示「当前模型未提供明确的积分价格，请刷新模型配置后重试」，改编与正文生成的价格在后台「剧本创作定价」里配置。
- 目标集数范围1～1000，单集目标时长 0～86400 秒。
- 剧本侧不提供导出功能；一个剧本项目只能绑定一份导入原文。
