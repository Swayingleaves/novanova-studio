# 图片创作

图片页是「左侧会话列表 + 右侧对话流」的双栏结构：左侧保存历史会话，右侧输入描述、调整参数、查看结果。

## 输入描述

在底部输入框写清主体、场景、构图、光线和风格，描述越具体越容易稳定复现。提交按钮会写明本次生成消耗的积分；生成过程中按钮变成停止（「停止生成」，排队阶段是「取消排队」）。

## 参考图

参考图有三种来源：直接上传本地图片、从「资产库」选择已有素材、从「最近上传」里挑一张。

- 支持多张参考图，数量上限由渠道决定（New API 格式渠道为 9 张），超出会在提交时报错。
- 参考图有顺序：描述里可以指明用途，例如「使用图片 1 的人物身份」「参考图片 2 的色彩关系」。提交前检查顺序。
- 结果卡片上的「加入参考图」可以把上一轮结果直接变成下一轮的参考图。
- 「资产库」弹窗只接受文本或图片类资产，选其它类型会提示「生图工作台只能使用文本或图片素材」。

## 图片设置

| 参数 | 可选值 | 默认 |
| --- | --- | --- |
| 模型 | 当前渠道中标记了「图像」能力、且配置了价格的模型 | 管理员配置的默认生图模型 |
| 画质 | 低画质、标准画质、高画质 | 标准画质 |
| 清晰度 | 1K、2K、4K | 2K |
| 比例 | 13 种：1:1、1:2、2:1、3:2、2:3、4:3、3:4、5:4、4:5、16:9、9:16、21:9、9:21 | 1:1 |

设置会记住上一次的选择（保存在浏览器里），新建会话不用重新调。

## 提示词优化

输入区的「AI优化提示词」会让 Agent 把描述补全成更具体的视觉细节，结果直接回填到输入框；失败时提示「提示词优化失败」。它使用管理员配置的默认文本模型。

## 生成与结果

- 状态依次是排队中、生成中、已完成；一次生成多张时会显示「已完成 N 张，失败 M 张」，失败卡片上会给出原因。
- 结果卡片的操作：**拷贝链接**、**上传到云储存**（上传后可「复制云储存地址」）、**添加到素材**、**加入参考图**、**下载**、**重新生成**。
- 「添加到素材」会把结果写进[我的资产](./assets)，来源标记为「生图工作台」；想在画布上使用，先存进资产，再到画布的「我的资产」里插入。
- 图片任务等待超过 5 分钟会被标记为生成失败（管理员可通过 `AI_TASK_WAIT_TIMEOUT_SECONDS` 调整）。

## 会话管理

左侧每个会话都保存在服务端，换设备登录也能看到；可以「修改标题」或「删除记录」，正在生成时不能删除。同一会话会保留每一轮的描述与结果，可以直接接着上一轮继续提要求。

```text
示例：保留人物身份和服装，将背景改为雨夜街道，使用冷色电影光。

示例：使用图片 1 的人物身份、图片 2 的色彩关系，换成 16:9 的横构图海报。
```

## 常见问题

- 提示「请联系管理员配置默认生图模型」：管理员尚未配置默认图像模型，或渠道下没有标记图像能力的模型。
- 模型下拉为空并提示「请先到配置里添加渠道和模型」：同上，需要管理员先完成渠道与模型配置。
- 提示「生成图片缺少媒体存储键」或保存素材失败：重新生成一次，并确认管理员已经配置默认对象存储。
- 生成连接中断提示「生成连接已关闭，请重新生成」：网络或服务端重启导致流式连接断开，重新提交即可。
