# 视频创作

视频页同样是「左侧会话列表 + 右侧对话流」的结构，参数比图片页多，且任务耗时更长——视频任务在服务端排队执行，前端展示实时状态。

## 选择生成模式

「Video Agent」面板里的**生成模式**有三项：

| 模式 | 说明 |
| --- | --- |
| 文生视频 | 只用文字描述生成视频 |
| 图生视频 | 以一张参考图作为首帧 |
| 全能参考 | 同时使用图片、视频（以及支持的模型下的音频）作为参考 |

当前模型支持哪些模式由管理员在模型能力里配置，因此切换模型后可用模式可能变少。在文生视频模式下直接上传素材，会自动切到图生视频或全能参考。

## 参考素材

- **参考图**：最多 9 张，单张不超过 30MB；超出时提示「已忽略超过 30MB 的参考图」。
- **参考视频**：最多 3 个，仅支持 MP4 / MOV，单条 2～15 秒，总时长不超过 15 秒；超出时提示「已忽略超过 50MB 的参考视频」。
- **参考音频**：仅画布支持，且需要模型开启音频输入，见[无限画布](./canvas)。

## 视频设置

| 参数 | 可选值 | 默认 |
| --- | --- | --- |
| 模型 | 当前模式下配置了价格的视频模型 | 管理员配置的默认生视频模型 |
| 比例 | Auto、16:9、4:3、1:1、3:4、9:16、21:9 | 16:9 |
| 清晰度 | Auto、480P、720P、768P、1080P、2K、4K——**只列出当前模型与模式下已配置价格的档位** | 720P |
| 时长 | 滑块加数值输入，范围取模型能力与计费最小时长的交集 | 模型默认值 |

## 首尾帧技能工作流

管理员可以用技能（流程提示词里带 `workflow: first-last-frame`）把一次生成拆成三个阶段：**生成首帧 → 生成尾帧 → 合成视频**。使用时的表现是：

- 面板会先显示各阶段报价，例如「工作流阶段报价：生成首帧 X 积分，…」，确认后再提交。
- 每个阶段有自己的进度，全部完成后给出最终视频。
- 提示「请先选择本次生成使用的图片模型与参数」或「请先确认视频比例、清晰度和时长」时，说明前置参数还没选全。
- 提示「积分不足，本次工作流需要 X 积分，当前可用 Y 积分」时，需要先补充积分。

## 任务状态与结果

- 状态包括：等待补充信息、生成中（视频任务会显示百分比进度）、工作流已完成、失败。
- 视频生成是异步任务，任务在服务端执行；重新打开页面后会重新订阅进行中的任务并继续显示进度。
- 结果操作：**拷贝链接**、**上传到云储存**、**添加到素材**（来源标记为「视频创作台」）、**下载**、**重新生成**。
- **视频编辑**（改画面、换音频等）由 Agent 工具承接，界面上没有独立入口——直接在对话里说明要改什么即可。

## 常见问题

- 提示「请联系管理员配置默认生视频模型」：管理员尚未配置默认视频模型。
- 提示「所选模型不可用，请联系管理员检查模型配置」：渠道或模型被停用、密钥失效或模型名不匹配。
- 生成超时：视频任务等待上限默认 15 分钟（`AI_TASK_VIDEO_WAIT_TIMEOUT_SECONDS`），上游渠道超时通常提示「视频生成超时，请稍后重试」。
- 提示素材校验失败：核对参考图数量、参考视频时长（2～15 秒、总时长不超过 15 秒）与文件格式。
- 更多排查手段见[常见问题](../troubleshooting/faq)。
