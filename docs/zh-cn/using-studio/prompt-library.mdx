# 提示词库

提示词库（页面标题是「提示词中心」）收集已经验证过的创作描述，可以在图片、视频和画布中直接复用。记录由管理员维护，普通用户负责浏览、复制和保存为素材。

## 浏览与筛选

- **搜索**：按提示词标题检索。
- **分类**：下拉选择，选项来自当前启用的提示词（分类由管理员填写，例如「摄影、海报、角色」）。
- **标签**：支持多选筛选。

列表是卡片网格，向下滚动自动加载（每页 20 条），到底后显示「已显示全部结果」，加载中显示「正在加载更多…」。排序由管理员的排序值决定，界面不提供排序控件。

卡片上显示封面或摘要占位、标题、更新时间、约 120 字摘要和最多 4 个标签；每张卡片有「复制」和「存为素材」。

## 查看与使用

- **查看详情**：点卡片打开弹窗，包含完整正文、分类与标签、创建时间与更新时间，底部按钮为「复制提示词」和「加入我的资产」。
- **复制**：把正文复制到剪贴板，提示「提示词已复制」。
- **存为素材**：写进[我的资产](./assets)，类型为文本、来源标记为提示词分类，提示「已加入我的资产」。
- **带入生成**：图片页、视频页输入区的「提示词库」按钮打开「选择提示词」弹窗，点「使用」后正文直接填入输入框，再按本次任务调整参数；画布节点上的「从提示词库选择」用法相同。

## 管理员维护

管理员在管理后台的「提示词库」标签里维护记录，字段包括标题、内容、分类、标签、预览内容、来源 URL、排序与状态。

- **启用 / 停用**：停用后用户侧不再展示（确认文案「停用后用户侧提示词库将不再展示该提示词。」），已经复制走的内容不受影响。
- **排序**：排序值越小越靠前，默认 1000。
- **预览内容**：支持 Markdown，用于在详情里展示参考图等说明。
- 来源 URL 目前在用户侧不展示。

后台的其它能力见[管理后台](./admin)。
