# 切换主题

主题偏好属于每个用户自己，不需要管理员操作，也不影响其他成员。

## 切换方式

点击左侧窄侧栏底部的主题按钮（太阳与月亮图标），在菜单里选择一种模式：

- **跟随系统**：跟随操作系统的浅色或暗色设置，菜单里会标出当前实际生效的主题。
- **浅色模式**
- **暗色模式**
- **紫色模式**

移动端点击左上角菜单打开导航抽屉，在“主题模式”一栏选择，效果相同。

## 保存位置

主题偏好保存在浏览器中（本地存储与 Cookie 各存一份），刷新页面或重新打开后仍然保留；换浏览器或换设备需要重新选择一次。

## 切换语言

点击侧栏底部的语言按钮（语言图标），选择 **简体中文** 或 **English**。移动端导航、画布工具栏、登录页面和文档头部也提供相同入口。

首次访问按浏览器语言偏好选择，未匹配到支持的语言时显示简体中文。手动选择保存在当前浏览器的Cookie中，有效期一年，刷新后继续生效。

切换语言不清空输入、画布、登录状态或正在执行的生成任务。界面、控件及网站系统提示随语言变化；你输入的内容、公告、作品、提示词和模型生成内容保持原文。文档切换会保留当前文章。
