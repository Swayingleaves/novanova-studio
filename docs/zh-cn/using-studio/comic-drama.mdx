# 漫剧创作

> **PRO 企业版功能。** 左侧导航中「漫剧创作」带 PRO 角标，仅在企业版授权下可用。

漫剧创作承接剧本创作产出的同一份剧本数据，负责把它做成画面：从视觉资产、镜头拆分，到分镜板编排、媒体生成与成片导出。**剧本与漫剧共用一份数据**，不会创建副本；剧本侧修改会登记为待审变更，由你决定是否更新下游内容。

## 三种进入方式

| 入口 | 做法 |
| --- | --- |
| 从剧本工作台 |顶栏「进入漫剧创作」，先做生产准备度检查 |
| 承接已有剧本 | 漫剧项目库右上「承接已有剧本」，从列表中选一个剧本 |
| 新建完整项目 | 漫剧项目库右上「新建完整项目」，同时创建共享剧本与漫剧工作台 |

「承接已有剧本」会使用同一份剧本数据，后续修改会同步回剧本创作。项目库卡片展示项目名、项目类型与制作阶段、制作进度、已完成镜头数、待更新项数量与任务状态。

## 生产阶段

左侧导航共 8 项，其中媒体生成中心通过顶栏按钮进入：

`生产准备 → 生产设置 → 镜头清单 → 视觉分镜板 → 视觉资产 / 声音对白 / 画布联动 / 待更新项`

打开工作台时会自动落到合适的阶段：已有镜头落到镜头清单，无镜头但剧本已就绪落到生产设置，否则落到生产准备。

### 1. 生产准备

「剧本生产准备度检查」逐项检查共享剧本、主要人物、场景与分集正文的完整度，状态为 `已具备 / 建议补充 / 缺失项`，检查项包括故事梗概、分集结构、可用剧本正文、场次生产信息、主要人物、场景地点、待确认 AI 草稿。

**系统不会自动补写或擅自修改剧本。** 缺失项可以点「去完善」或「编辑剧本」跳回剧本工作台；也可以「继续制作流程」直接往下走。

### 2. 生产设置

「项目生产设置」定义全局画面比例、视觉风格、时长与目标平台。视觉风格会作为自动拆镜头、提示词合成与生成的默认标准注入。

| 配置项 | 说明 |
| --- | --- |
| 项目类型 | 漫剧 / 真人短剧 / 动画 / 广告故事 / 音乐视频 / 故事短片 |
| 画面方向 | 竖屏（9:16）/ 横屏（16:9）/ 方形（1:1），切换时会自动改写画面宽高比 |
| 画面宽高比 | 9:16 / 16:9 / 1:1 / 4:3 / 2.35:1 |
| 目标总集数 | 1～1000 |
| 单集目标时长 | 0 表示不限制，短剧通常60～120 秒 |
| 预计全片总时长 | 0 表示按集数自动折算 |
| 默认视觉风格与画风标准 | 注入镜头提示词与资产图生成；提供 7 个快捷风格预设 |
| 时代背景与整体氛围 | 影响镜头画面氛围 |
| 目标发布平台 | 抖音 / 快手 / 微信视频号 / B站 / 小红书 / YouTube / TikTok 等可点标签追加 |
| 具体使用场景 | 例如商业短剧宣发、IP 故事孵化 |

### 3. 视觉资产

管理人物、场景与道具的视觉基准。每个资产可以派生多个版本（如常服、战损、夜雨），镜头精确绑定资产版本，保证全片视觉一致。

- 类型筛选：全部 / 人物 / 场景 / 道具，可按名称与描述搜索。
- 批量操作：全选当前、**仅选未生成图**、「批量生成资产图」（每个资产取最新版本，没有版本的资产会被跳过并提示数量）。
- 资产卡片显示类型、描述、引用镜头数与版本数；有上游变更时显示「需要更新」标签。
- 版本变体类型：默认基准 / 服装变更 / 年龄时期 / 光照/天气 / 伤损/变身状态。

AI 资产图生成可选生成模型、画质（低/ 标准 / 高）、清晰度（1K / 2K / 4K）与画面比例。形态是固定的：人物输出纯白背景三视图设定图，道具输出纯白背景多视角设定图，场景输出不含人物与剧情动作的空景设定图。

### 4. 镜头清单

「镜头拆分与清单」把剧本场次拆解为可执行的画面镜头单元。

- **AI 自动拆分镜头**：选择拆分范围（分集）、可选指定场次、预计镜头数量（1～50，**默认留空，由 AI 按剧本内容自行判断**）、叙事节奏（紧凑利落 / 高潮反转 / 舒缓写意 / 激烈打斗）、创作重点指示（可选，例如「突出人物冲突与关键动作」）与拆分模型。生成的草稿**必须审核确认后才生效**。
- 草稿审核抽屉里可逐镜微调景别、时长（0.5～60 秒）、画面描述、对白与旁白、运镜调度、光线氛围，然后「保存微调」或「确认生效为正式镜头」；最后一个镜头不可删除。
- 镜头卡片包含画面构图与内容、对白与声音、光线氛围与关联资产版本、最终视频提示词。
- 景别六档：远景 / 全景 / 中景 / 近景 / 特写 / 大特写。
- 摄影机运动七档：固定镜头 / 缓慢推进 / 缓慢拉远 / 横向摇摄 / 纵向俯仰 / 跟随移动 / 环绕旋转。
- 工具栏支持「分集筛选」「场次筛选」「仅选未生成提示词」与「批量生成最终提示词」。
- 删除镜头会先做影响预检：若该镜头已关联生成的图片或视频，会提示将级联删除提示词版本、绑定关系与媒体记录，且不可逆。

### 5. 视觉分镜板

顶栏可切换两种视图：**时间轴** 与**网格板**，并提供分集筛选、保存、导出视频与批量媒体生成。

**网格板**：按镜头排成网格，显示画面/视频、镜号、时长、画面描述与失败原因；点视频卡打开播放器，点「在工作台预览」跳回时间轴并定位播放头。网格板不提供编辑与生成操作。

**时间轴**：3D 翻转工作台，正面「视频预览」、背面「生成配置」。

- 预览面支持播放/暂停、上一个/下一个镜头、时间码与进度条、静音开关；预览画面上会按当前时刻渲染文字叠字层，可拖动改位置、拖右下角改字号（12～120）、双击或右键编辑。
- 配置面展示最终视频提示词（`已采用 v{n}`）、上次生成快照提示词、画面构图与动作调度、对白与音效、光线氛围与运镜、关联视觉资产与参考图、生成任务快照参数，并提供「复制提示词」「编辑镜头」「生成此镜头」。
- 底部**分镜轨道**有四条：视频轨道、文字轨道（最多 3 条）、音频轨道。文字片段左右边缘可拖拽裁剪时间、拖动改位置，同一轨道的片段不能重叠；音频片段可拖动与两端裁剪。
- 缩放用 `Ctrl/⌘ + 滚轮` 或两侧按钮，普通滚轮横向滚动；空格键播放/暂停。
- 顶部显示「待保存 N 项」，无冲突时每 15 秒自动保存一次；切走阶段、返回项目库或关闭页面时若有未保存改动，会弹「时间轴有未保存的修改」，可选「保存后离开 / 不保存并离开 / 继续编辑」。

**添加文字**：内容（≤2000 字）、字体（中文黑体 / 宋体 / 霞鹜文楷，英文 Inter / Montserrat / Lora / Caveat）、字号（12～120）、对齐方式、文字颜色、可选背景色。三条文字轨道在同一时间都占满时无法再添加。

**添加音频**：可关联已有声音条目或新建（对白 / 旁白 / 环境声 / 音效 / 配乐），上传 MP3 或 WAV（单文件≤ 15 MB），设置时间轴起点与裁剪起止。「移出轨道」只解除排期，声音条目与文件保留。

**批量媒体生成**：可一次勾选当前分集的多个镜头批量生成视频，右侧显示已采用提示词数量、参考图分布（按图生视频）与预估总价，参数变化后自动重新估算。

### 6. 媒体生成中心

按各镜头已采用的提示词与视觉资产生成分镜图片或单镜头视频。所有生成版本完整存档，可以试看、对比并明确采用最佳版本。

- 筛选类型（图片 / 视频）与状态（已采用版本 / 已完成 / 处理中 / 失败）。
- 每条记录可「设为采用」「停止」（停止后已扣积分自动退回）或「重试」。
- 新建任务时选择目标镜头、媒体类型、生成模型；视频模式会显示关联参考图，有参考图自动进入图生视频，无参考图则走文生视频。
- 生成目标仅支持镜头与资产版本，媒体类型仅支持图片与视频。

### 7. 声音对白

「声音与对白编排」结构化管理角色对白、旁白解说、环境音效与背景音乐建议。

- 「从镜头提取对白」会扫描所有含台词的镜头批量创建对白声音轨，已存在的自动跳过。
- 类型：对白 / 旁白 / 环境声 / 音效 / 配乐。
- 字段：内容或声音描述、语气、情绪、语速倍率（0.5～2.0）、音色/配音模型，可关联镜头。
- 这里是结构化登记声音条目与参数；真正的音频文件上传在分镜板时间轴完成。

### 8. 画布联动

漫剧创作负责结构化项目管理与镜头流水线，无限画布负责自由探索视觉创意、多方案对比与综合编排，两端数据双向联动。可以在画布中引用当前项目的角色设定图、镜头提示词与分镜脚本节点进行连线与视频合成，画布中确认采用的媒体结果可回写到漫剧工作区的镜头与资产版本。「手动绑定节点」可把镜头或资产绑定到指定画布节点。

### 9. 待更新项

「上游变更联动管理」在共享剧本、人物设定或场景描述修改后，精准追踪受影响的下游镜头与资产，并保留全部既有生成成果。**未经明确确认，绝不自动覆盖或重复扣费。**

| 剧本侧操作 | 影响范围 |
| --- | --- |
| 改故事概览、大纲、分集顺序或恢复历史版本 | 标记全部镜头与资产 |
| 改分集| 该分集下所有镜头 |
| 改场次 | 该场次下所有镜头 |
| 改人物或世界观 / 地点 | 通过资产版本与来源实体关联到的镜头与资产 |

每条变更按来源分组，展示「影响：N 个生成结果 · N 个提示词版本」与「确认更新后」该去哪个阶段处理。处理方式只有两种：

- **保留旧结果**：关闭影响项，不触发重新生成，历史生成成果继续使用。
- **确认更新**：只关闭影响项并打上「需要更新」标记，**不会自动重新生成**，你再到对应阶段自行处理。

「需要更新」只表示剧本来源变了，不代表历史生成结果失效。

## 辅助工具

**批量生产**（顶栏「批量生产」）：两个页签「发起批量生成」与「进度监控」。

- 生成范围：`未完成镜头` / `全剧全部镜头` / `按指定分集批量生成`。
- 媒体类型只有分镜图片与镜头视频；画面比例三档 9:16 / 16:9 / 1:1，默认跟随项目画面方向。
- 系统基于各镜头**已采用的提示词**生成，已完成的镜头不会被重复处理。
- 进度监控显示状态（已全部完成 / 执行失败 / 排队处理中）、完成/排队/失败数量与消耗预估。

## 导出成片

分镜板顶栏「导出视频」→「导出分镜视频」。

- 当前范围为全部分集或当前分集；成片包含视频、文字和音频轨道，**缺失镜头保留黑画面，最长 10 分钟**。
- 导出前会强制保存未保存的时间轴改动，保存失败则无法导出。
- 完成后可「下载 MP4」；导出中可以「取消导出」，失败可「重新导出」。

## 相关限制

| 项目 | 限制 |
| --- | --- |
| AI 拆分预计镜头数量 | 1～50；默认留空表示不指定，由 AI 按剧本内容自行判断 |
| 镜头时长 | 0.5～120 秒（草稿审核与分镜板弹窗为 0.5～60 / 1～60 秒） |
| 目标总集数 | 1～1000 |
| 文字片段 | 内容 ≤ 2000 字，字号 12～120，最多 3 条文字轨道 |
| 音频文件 | MP3 / WAV，单文件 ≤ 15 MB |
| 语速倍率 | 0.5～2.0 |
| 视频导出总时长 | ≤ 10 分钟 |
| 批量生成媒体类型 | 仅图片与视频；生成目标仅镜头与资产版本 |
| 时间轴保存 | 无冲突时每 15 秒自动保存；有待保存项时禁止导出 |
| 项目库分页 | 每页 12 条 |

## 与剧本创作的衔接

- 剧本工作台顶栏「进入漫剧创作」会先保存，再做生产准备度检查，确认后跳转到漫剧工作台。
- 漫剧工作台顶栏「剧本工作台」直接回到剧本项目。
- 「承接已有剧本」与「新建完整项目」都不会复制项目数据，两侧修订号各自独立递增。
- 剧本侧每次改动只会登记待审项，**不会**自动改动镜头、资产与媒体状态。
