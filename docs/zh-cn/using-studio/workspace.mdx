# 认识工作台

工作台左侧是按「创作、资源、设置」分组的导航，右侧是各功能的操作区；全局入口集中在顶部工具区和侧栏底部。

## 左侧导航

桌面端使用窄侧栏（88px），移动端点击左上角菜单打开「创作导航」抽屉——抽屉里会显示分组标题，桌面窄侧栏只平铺图标。

| 分组 | 入口 | 做什么 |
| --- | --- | --- |
| 创作 | 图片 | 生成、编辑和管理图片会话 |
| 创作 | 视频 | 创建视频、选择参考素材并查看异步任务进度 |
| 创作 | 无限画布 | 把文本、图片、视频、音频和生成结果组织在同一个可编辑空间 |
| 资源 | 我的资产 | 集中管理上传素材和已保存结果 |
| 资源 | 提示词库 | 复用常用提示词，减少重复输入 |
| 设置 | 管理后台 | **仅管理员可见**，管理用户、模型、技能、提示词、公告与接口记录 |

进入某个具体画布（`/canvas/<画布 id>`）时，左侧导航会自动隐藏，把空间让给画布。

## 侧栏底部的三个按钮

- **系统公告**（铃铛）：打开公告列表，有未读时显示小红点。见[系统公告](./announcements)。
- **配置**（齿轮）：只有管理员可见，打开「配置与用户偏好」。见[系统配置](./system-configuration)。
- **主题**（太阳与月亮）：切换跟随系统、浅色、暗色和紫色。见[切换主题](./theme)。

## 顶部与右上角

- **文档**：打开本使用指南。
- **GitHub**：只有部署时配置了 `NEXT_PUBLIC_GITHUB_URL` 才会出现。
- **积分与用户菜单**：未登录时显示「登录」按钮；登录后显示积分余额与头像，悬停展开菜单——用户信息与专属邀请链接、购买积分、兑换积分、积分记录，管理员会多一项「系统管理」，最后是「退出登录」。

画布页面顶部有自己的一栏工具，其中的用户菜单还多了「画布快捷键」入口。

## 权限差异

普通用户和管理员看到的界面基本一致，区别只有三处：管理后台入口、侧栏底部的配置齿轮、用户菜单里的「系统管理」。

另外，当管理员尚未配置默认模型时：管理员点击提示会直接打开配置弹窗，普通用户看到的是「请联系管理员配置默认生图模型」或「请联系管理员配置默认生视频模型」。
