# 系统配置

系统配置由管理员维护，普通用户无需改动。配置保存在服务端，工作台页面不会展示渠道密钥与存储凭证。

## 打开配置弹窗

- **侧栏齿轮**：左侧窄侧栏底部的齿轮按钮，只有管理员能看到。
- **画布顶栏**：画布页面右上角工具区的配置图标。
- **缺模型时的提示**：图片、视频、画布页提示「没有配置默认模型」时，管理员点击提示会直接打开弹窗。

弹窗标题是「配置与用户偏好」，分五个标签页：**我的渠道、我的模型、积分设置、邀请奖励、对象存储**，打开时默认停在「我的渠道」。非管理员账号看不到入口；弹窗本身也会在角色不是管理员时自动关闭。

## 通用约定：先落草稿，再按页保存

- **没有全局保存按钮**，每个标签页各有自己的「保存」，没有改动或正在保存时按钮是灰的。
- 新增渠道、编辑模型都先写进草稿，必须点该页的「保存」才提交到服务端，成功提示「渠道配置已保存」「模型配置已保存」「积分设置已保存」等，失败会给出具体原因（如「保存对象存储失败」）。
- 有未保存改动时关闭弹窗会先确认：「放弃未保存修改？」/「关闭后会丢弃所有 Tab 中未保存的修改。」，可选「放弃修改」或「继续编辑」。
- 保存后**管理员这边立即生效**；普通用户的配置在登录初始化时拉取，需要刷新页面才能看到新的模型与价格。
- 任务执行时才读取当前配置（队列里只存任务 id），所以新提交的任务使用最新设置，已经创建的任务保留创建时的模型快照。

## 我的渠道

渠道是「调用某个 AI 服务的入口」，一个渠道对应一套 Base URL 与密钥。

| 字段 | 说明 |
| --- | --- |
| 渠道名称 | 便于识别的名字；留空时列表显示「未命名渠道」 |
| 调用格式 | OpenAI / New API / Evolink / Gemini / Agnes / Anthropic / Seedance / MiniMax / 自定义 |
| Base URL | 服务地址。切换调用格式时，如果地址为空或仍是旧格式的默认值，会自动替换为新格式的默认地址 |
| API Key | 密钥，界面默认打码，可以点眼睛图标查看 |
| 模型列表 | 该渠道可用的模型名，可以手动输入，也可以拉取 |

各调用格式的默认 Base URL：

| 调用格式 | 默认 Base URL |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| New API | 无默认值，需自行填写 |
| Evolink | `https://api.evolink.ai/v1` |
| Gemini | 以 `/v1beta` 结尾的地址 |
| Agnes | 无默认值，需自行填写 |
| Anthropic | `https://api.anthropic.com/v1` |
| Seedance | `https://ark.cn-beijing.volces.com/api/v3` |
| MiniMax | `https://api.minimaxi.com` |
| 自定义 | 无默认值，需自行填写 |

**拉取模型**：填好 Base URL 与 API Key 后点「拉取模型」，结果会写入模型列表并提示「<渠道名> 模型列表已更新，请点击保存」；缺少参数时提示「请先填写该渠道的 Base URL 和 API Key」。MiniMax 与自定义格式的按钮是禁用的（「MiniMax 请手动配置 MiniMax-H3」「自定义格式请手动配置模型列表」），模型名需要手动维护。

**删除渠道**：确认文案是「该渠道会在点击保存后从服务端删除。」；如果还有模型引用它，会提示「请先在“我的模型”中删除关联模型并保存，再删除渠道」。

渠道没有启用/停用开关，也没有独立的连通性测试按钮——要验证密钥是否有效，用「拉取模型」最直接。密钥虽然界面打码，但列表接口返回的是明文，请注意不要在共享屏幕上打开这个弹窗。

## 我的模型

模型来自「我的渠道」：先在渠道里填写或拉取模型名，再回到这里为每个模型补能力与价格。没有模型时这里会提示「请先在“我的渠道”中添加模型，再配置可选模型」。

### 1. 选择要配置的模型

页面顶部的三个「可选项」下拉，分别在图像、视频、文本三类里挑选要配置的模型；每个模型一行，显示「展示名」和一个「默认」标记，点「编辑」进入配置弹窗。

三个「默认模型」选择器决定生成页的初始模型：默认生图模型、默认生视频模型、默认文本模型。

### 2. 标记能力

| 类型 | 可选能力 |
| --- | --- |
| 文本 | 常规聊天、图像理解 |
| 图像 | 文生图、图生图 |
| 视频 | 文生视频、图生视频、全能参考、首尾帧原生生成、支持音频输入 |

**能力决定入口**：只有标记了对应能力的模型才会出现在对应的生成页；没有开启「支持音频输入」的视频模型在画布上无法引用音频。

### 3. 展示名称与图标

- **展示名称**：生成页下拉里显示的名字；留空或与真实模型名一致时按真实名显示。
- **展示图标**：可选「自动匹配 / 默认（Clapperboard）/ Agnes / Seedance（字节跳动）/ Claude / OpenAI / Gemini / DeepSeek / GLM / Grok / MiniMax」，自动匹配会按模型名推断。

### 4. 计费与价格

- **文本、图像模型**：只有一个「每次积分」字段，按次计费。
- **视频模型**：先选「计费方式」——按次或按秒；按次只需填各分辨率档位的「积分/次」；按秒还要填「最短生成时长（秒）」（最小 1、默认 3）。价格表按生成模式 × 分辨率（480P / 720P / 768P / 1080P / 2K / 4K）逐档填写，未填的档位显示「未配置」，用户在生成页也就选不到该档位。
- 计算方式：按次＝单价 × 生成数量；按秒＝单价 × 秒数 × 生成数量。配置弹窗里没有报价预览，报价在生成页和画布上展示。

### 5. 自定义格式的请求与响应模板

调用格式选了「自定义」的渠道，其模型要在这里填写自定义 JSON（请求模板与响应解析）。模板可用变量：`{{prompt}}`、`{{model}}`、`{{references}}`、`{{videoReferences}}`、`{{audioReferences}}`、`{{size}}`、`{{resolution}}`、`{{seconds}}`、`{{count}}`、`{{taskId}}`，请求方法可选 POST 或 GET。JSON 格式不对时会提示「模型自定义JSON必须是对象」或「模型自定义JSON格式不正确」。

### 6. 常见拦截

- 「模型配置引用了未保存的渠道或模型，请先保存“我的渠道”」：先去渠道页保存，再回来保存模型。
- 视频模型的计费方式必选、价格必须是不小于 0 的整数，且只能配置已勾选的生成模式与模型支持的分辨率，否则服务端会拒绝保存。

## 积分设置

只有一项：**初始积分**（默认 100），用来设定之后注册、后台创建或首次第三方登录的新用户起始余额。说明文案是「只影响之后注册的用户，已有用户积分不会自动变更」。

已有用户要调整积分，到管理后台「用户管理」里用「调整积分」，需要填写原因（会写入用户的积分流水）。

注意：**生成任务的扣费不在这里**，而是在「我的模型」里按模型配置。

## 邀请奖励

只有一项：**每名新用户奖励积分**，没有开关，设为 0 即暂停发放。说明文案是「新用户通过有效邀请链接完成邮箱注册或首次第三方登录后，奖励发放给邀请人。设置为 0 表示暂停发放；只影响之后注册的用户，不追溯历史邀请。」

- 它与「初始积分」是两个独立配置，互不影响：初始积分给新用户自己，邀请奖励给邀请人。
- 邀请链接在「个人信息」页的「专属邀请链接」里复制，见[个人信息](./profile)。

## 对象存储

对象存储用于保存上传素材、头像和生成结果。可以配置多条，但必须指定一个默认项：保存时没有默认项会提示「请设置默认对象存储」；站点里第一条被创建的存储会自动成为默认。

系统按**私有读私有写**方式使用存储桶：对象键照常保存，浏览器、第三方模型和服务端拿到的读地址由服务端在返回响应前临时预签名，过期后重新签发。桶权限必须是「私有读写」；如果桶仍是公有读，拿到地址的人可以绕过签名直接匿名读取，预签名就失去意义。

### 预签名有效期

预签名读地址按用途分档，由部署环境变量控制，单位为秒；不配置时使用默认值：

| 环境变量 | 用途 | 默认值 |
| --- | --- | --- |
| `STORAGE_SIGN_PREVIEW_SECONDS` | 页面预览，图片、视频、音频播放 | 3600 |
| `STORAGE_SIGN_DOWNLOAD_SECONDS` | 文件下载 | 300 |
| `STORAGE_SIGN_THIRD_PARTY_SECONDS` | 第三方模型拉取参考素材 | 7200 |
| `STORAGE_SIGN_PUBLIC_PAGE_SECONDS` | 公开分享页展示 | 1800 |

有效期越短越安全，但过短会让长视频播放、大文件下载或排队较久的生成任务在读取时遇到签名过期而 403。改完变量需要重启服务端；Docker 部署要重新创建服务端容器，单纯 restart 不会重新注入环境变量。

### 通用字段

| 字段 | 说明 |
| --- | --- |
| 配置名称 | 这条配置的名字 |
| 服务商 | 腾讯云COS / 阿里云OSS / 七牛云Kodo |
| 存储目录 | 上传 Key 的前缀，默认 `novanova-studio`；规则是「目录/images 或 videos/日期/文件名」 |
| Bucket | 存储桶 |
| Region | 地域 |
| 签名/访问域名 | 可留空。留空时按服务商规则自动生成访问前缀；界面旧称「公开访问地址」（接口字段 `publicBaseUrl`） |

### 各服务商的差异

| 服务商 | 密钥字段 | 额外要求 |
| --- | --- | --- |
| 腾讯云COS | SecretId / SecretKey | 桶权限必须是**私有读写**。签名/访问域名留空时使用 `https://{bucket}.cos.{region}.myqcloud.com/{key}`。 |
| 阿里云OSS | AccessKey ID / AccessKey Secret | **必须填 Endpoint**（要带 `http://` 或 `https://`）与地域 ID（如 `cn-hangzhou`）；签名/访问域名留空时按 Bucket 与 Endpoint 自动生成 |
| 七牛云Kodo | AccessKey / SecretKey | 区域从下拉选择（华东-浙江 z0、华东-浙江2 cn-east-2、华北-河北 z1、华南-广东 z2、北美-洛杉矶 na0、亚太-新加坡 as0）；**必须填已绑定该 Bucket 的 CDN 或自定义域名** |

切换服务商会清空已填的密钥、Bucket、Region、Endpoint 与签名/访问域名。

### 私有桶注意事项

- **桶权限**：必须是「私有读写」。对象 ACL 优先级高于桶 ACL——历史上被单独设成 `public-read` 的对象，即使桶改成私有仍能匿名读取；切私有时要一并检查并改回 `private`，切换与验证步骤见仓库 `docs-api/对象存储私有读写切换与验证.md`。
- **CDN 域名**：签名/访问域名填 CDN 域名时，必须同时开启 CDN 服务授权与回源鉴权，否则私有桶下 CDN 回源会被拒绝，页面图片、视频会 403 或裂图。COS 预签名地址绑定 COS 域名，不能直接把链接换成 CDN 域名使用；本期建议留空，或使用直连 COS 的自定义源站域名。
- **默认域名**：2024-01-01 之后创建的 COS 桶，默认域名不支持浏览器预览（响应带 `Content-Disposition: attachment`，打开即下载），需要预览时绑定自定义源站域名，并保证签名地址的 Host 与域名一致。
- **签名过期**：分享页、长视频长时间停留后出现 403，通常是签名过期，刷新或重新进入页面即可；频繁出现时调大对应的 `STORAGE_SIGN_*` 变量。
- **凭据边界**：签名 URL 本身就是临时凭据，有效期内任何人都能访问；不要把它写回数据库或画布 JSON，不要粘贴到工单、日志或公开渠道，也不要把永久密钥放到前端。
- **强制私有开关**：部署环境变量 `STORAGE_REQUIRE_PRIVATE_BUCKET` 默认 `false`，检测到桶仍允许匿名读取时只记录告警并继续；切换为私有读写后建议设为 `true`，此时小说原文导入、分享副本等私有内容在公开桶上会被拒绝。

### 测试与默认

- **测试上传**：填完必填项后点「测试上传」。若还没保存，会提示「请先保存对象存储配置，再执行测试上传」——即**先保存，再测试**。成功会写入一个文本测试文件，提示「对象存储测试上传成功，请点击保存记录测试时间」，并给出「打开测试文件」链接；该链接是限时预签名地址，几分钟内有效。失败会直接显示后端原因，例如「腾讯云COS SecretId不能为空」「阿里云OSS Endpoint必须是HTTP或HTTPS地址」「七牛云Kodo区域ID不受支持」。
- **读取探测**：测试上传的完整流程是「上传测试对象 → 尝试生成预签名地址并记录 GET 状态 → 匿名 HEAD 检查是否 403 → 删除测试对象」。探测失败只写告警日志，不会阻断保存；日志出现 `对象存储已拒绝匿名读取` 表示私有读已生效，`对象存储仍允许匿名读取` 表示桶或对象仍可被匿名访问，需要检查桶 ACL 与历史对象 ACL。
- **设为默认**：行内按钮「设为默认」，已是默认时置灰；标题会带「默认 · 」前缀并显示「上次测试 …」或「尚未测试」。
- **删除**：默认项不能删（「默认对象存储不能删除，请先设置其他默认项」）；只剩一条时会提示「至少保留一个对象存储」。非默认项是物理删除，没有「是否仍被素材引用」的保护，删前请确认没有素材还在用它。
- 配置不完整时保存会被拦下，提示类似「请完整填写访问密钥、密钥、Bucket 和 Region」「请填写阿里云OSS Endpoint」「请填写七牛云Kodo公开访问地址」。

## 生效范围与排查

- 保存渠道或模型后，生成页会立刻出现新的模型与价格；普通用户刷新页面即可看到。
- 图片或视频页提示没有可用模型，或上传素材、保存结果失败，先回到这里确认默认模型与默认对象存储是否配置完成。
- 渠道密钥与存储凭证不要提交到 Git，也不要粘贴进 Issue 或截图。
- 用户、技能、提示词与公告的管理见[管理后台](./admin)；这些配置在使用侧的表现见[图片创作](./image-generation)、[视频创作](./video-generation)、[无限画布](./canvas)。
