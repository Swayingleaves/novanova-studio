# 我的资产

「我的资产」集中管理可复用的素材：生成结果、上传文件、提示词正文都能存进来，再在图片、视频或画布中反复使用。资产只属于当前用户。

## 页面一览

- 顶部按钮：**导出**、**导入**、**新增资产**。
- 搜索框按「标题、内容、标签或来源」检索。
- 类型筛选：全部 / 文本 / 图片 / 视频（暂时没有来源、标签、时间筛选，也没有排序控件）。
- 展示为响应式网格，底部可切换每页 12 / 24 / 48 条，空态是「没有找到资产」。

## 新增与编辑

「新增资产」和卡片上的「编辑」使用同一个弹窗：

| 字段 | 说明 |
| --- | --- |
| 类型 | 文本或图片 |
| 标题 | 便于检索的资产名称 |
| 封面 | 填图片 URL，或点「上传」 |
| 标签 | 输入后回车添加 |
| 来源 | 默认「手动添加」 |
| 备注 | 额外说明 |
| 内容 | 文本资产填正文；图片资产点「选择图片」 |

## 卡片与操作

卡片显示封面（没有封面时显示「暂无封面」，文本类直接展示正文片段）、标题、来源（没有则显示「未标注来源」）、类型、摘要以及最多 3 个标签。图片和视频的摘要会显示「宽 × 高、大小、格式」。

每张卡片可以：

- **查看**：打开预览弹窗。图片显示尺寸、大小与格式，视频可直接播放，文本显示全文；底部是「复制文本」或「下载图片 / 下载视频」。
- **编辑**（视频除外）：改标题、封面、标签、备注与内容。
- **复制**（仅文本）、**下载**（图片与视频）。
- **删除**：确认文案是「「X」将从资产库中移除，此操作无法撤销。」，成功后提示「资产已删除」。

## 资产从哪里来

| 来源标识 | 产生方式 |
| --- | --- |
| 手动添加 | 资产页「新增资产」 |
| 生图工作台 | 图片页结果卡片「添加到素材」 |
| 视频创作台 | 视频页结果卡片「添加到素材」 |
| Canvas | 画布节点悬停工具栏「存资产」 |
| 提示词分类名 | 提示词库卡片「存为素材」 |

## 导出与导入

「导出」会把当前资产打包成 `我的资产.zip`；「导入」只接受 `.zip` 文件，选错会提示「导入失败，请选择有效的资产压缩包」。适合在不同环境之间搬运素材。

## 注意事项

- 上传前需要管理员配置默认对象存储，否则会提示「请联系管理员配置默认对象存储」或「请联系管理员完整配置默认对象存储」。
- **删除资产只会删除资产记录，不会删除对象存储里的文件**；需要回收存储空间时要在对象存储侧另行清理。
- 目前没有多选和批量删除，只能逐个删除。
- 想在生成或画布里使用这些素材，见[图片创作](./image-generation)、[视频创作](./video-generation)和[无限画布](./canvas)。
