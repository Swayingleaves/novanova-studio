# 系统公告

公告用于发布功能更新、维护通知和重要提醒，由管理员在后台发布，所有用户都能看到。

## 在哪里看

- **桌面端**：左侧窄侧栏底部的铃铛按钮。有未读公告时按钮上会出现小红点。
- **画布页面**：右上角工具区的铃铛，带未读数量角标。
- 未登录时点击铃铛会先弹出登录框。

## 列表与详情

- 列表以浮层展示，标题是「系统公告」，未读条目会高亮并带圆点，空态为「暂无公告」；打开面板时会立即刷新一次。
- 点开一条公告打开展示弹窗，标题就是公告标题（没有标题时显示「公告详情」），内容为空时显示「暂无内容」，底部会标出发布时间与创建时间。
- 弹窗按钮：「我已阅读」标记当前公告为已读并关闭；「全部已读」一次清空未读。标记失败会提示「标记公告已读失败，请稍后重试」。

## 更新时机

登录后客户端每 30 秒拉取一次公告，所以管理员发布后最长约 30 秒就能看到（打开面板会立即刷新）。公告没有实时推送。

## 管理员如何发布

在管理后台的「消息管理」里新建公告，填好标题与内容后先保存为草稿，再点「发布」，确认文案是「发布后所有用户将看到此公告，确定发布？」。详见[管理后台](./admin)。
