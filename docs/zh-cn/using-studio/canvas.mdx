# 无限画布

画布适合整理复杂的创作流程：把文本、图片、视频、音频、分镜和生成结果摆在一个可缩放的空间里，用连线表达引用关系，再让画布 Agent 按上下文继续创作。

## 节点类型

| 节点 | 用来做什么 |
| --- | --- |
| 文本 | 写提示词、剧本或说明；点击正文即可编辑 |
| 图片 | 展示素材或生成结果，支持复制提示词、替换、锁定比例、裁剪、切图、看大图 |
| 视频 | 播放、生成视频、合成素材 |
| 音频 | 试听、看波形、裁剪出新节点 |
| 分镜脚本 | 由剧本生成的分镜列表，可「开始生成」「重新生成分镜脚本」「打开分镜脚本」 |
| 合成视频 | 把最多 20 段视频节点按顺序合成 |
| 背景板 | 给一组节点加底板，便于整体移动和说明用途 |

新增节点有两条路：底部工具栏（移动/选择、撤销、重做、文本、图片、音频、视频、背景板、上传素材、我的资产、删除选中、清空画布），或右键空白处（空白的右键菜单里还有「添加背景板」）。

## 基本操作

- **平移**：拖动画布空白处；**缩放**：滚轮或右下角滑杆，范围 0.05～5。
- **连线**：从节点连接点拖到另一个节点；拖到空白处会弹出菜单，可选「引用该节点生成」，包括文本生成、图片生成、视频生成、设定图、合成视频、分镜脚本。
- **框选**：`Ctrl/Cmd` + 拖动；`Shift/Ctrl/Cmd` + 点击可追加选择；`Ctrl/Cmd + A` 全选。
- **复制粘贴**：`Ctrl/Cmd + C` / `V`，副本标题会加「 副本」后缀。
- **删除**：`Delete` / `Backspace`，会先弹确认框（删除背景板会连带成员，确认框里写明「此操作可通过撤销恢复」）。
- **撤销 / 重做**：`Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z`（或 `Y`），最多保留 50 步。
- **节点尺寸**：图片节点默认锁定比例，可切换为自由比例；图片节点最小 220×160，音频节点最小 280×150。
- **背景板**：拖动板体会带着成员一起移动，缩放板体会自动包住成员；选中后可在工具栏改名并挑一个底色。

## 画布 Agent

顶部的「画布Agent」打开对话面板，它读取当前节点、连线、选区和视口，可以创建/移动/缩放/删除/连接节点、调整视口，也可以直接发起文本、图片、视频生成。

- 涉及生成但缺少必要参数时，它会先追问（例如「图片尺寸不能为空，请先向用户确认尺寸」）。
- 需要改动画布的操作会先给出「等待确认」卡片，点「执行」才会生效。
- 处理中再次发送消息会被忽略；面板支持「新对话」与收起，历史只取最近 12 条。
- 也可以按住 `Ctrl/Cmd + Shift` 把节点直接拖进 Agent 面板作为上下文。

## 引用素材：@ 提及

在节点下方的提示词输入框里输入 `@` 会弹出「引用画布资产」列表，可以搜索并选择画布上已有内容的节点（图片、视频、音频、文本，以及图片/视频节点里的提示词）。选中后会自动把源节点连到当前节点，并在提示词里插入「参考图1」「视频1」「音频1」「文本1」这样的标签。

- 引用音频需要模型支持音频输入，否则提示「当前模型或生成模式不支持音频输入」。
- `@` 的候选只来自画布节点；想用资产库里的素材，用面板上的「从提示词库选择」或工具栏的「我的资产」。
- Agent 面板不用 `@`，改用 `Ctrl/Cmd + Shift` 拖节点。

## 设定图

设定图用于角色与场景设计。两个入口：从文本或图片节点的连接点拖出选择「设定图 · 角色与场景设计参考」，或在图片节点的面板里用「设定图：<技能名>」下拉切换。

- 生成时会把技能的流程提示词与你的描述合并，只生成 1 张图，比例取技能配置的比例（默认 16:9），节点标题为「设定图·<技能名>」。
- 视频、分镜、背景板、合成视频节点不支持，会提示「暂不支持设定图」；没有描述也没连上有内容的上游节点时提示「请输入生成描述或连接有内容的上游节点」。

## 音频与视频的音频输入

拖入文件、用工具栏「上传素材」、或在音频节点上点击空态都能加入音频；仅支持 MP3 / WAV，单文件不超过 15MB。音频节点提供波形、播放/暂停、点击波形或方向键定位。

**裁剪**：悬停音频节点工具栏点「裁剪（裁剪为新音频节点）」，在弹窗里调起止区间并试听，点「创建音频节点」。原节点保持完整音频，新节点引用选中的片段（片段过短会报错）。

**给视频加音频**：只有视频节点、且模型开启了音频输入、模式为全能参考时可以引用音频，否则会提示不支持并自动切到全能参考模式。

## 自动保存与项目

- 画布会自动保存到服务端（节点、连线、视口、对话、偏好），改动后约 400ms 防抖写入，没有手动保存按钮。
- 刷新后节点、连线、视口、对话都会恢复；刷新时正在进行但还没拿到任务 id 的节点会被标为失败，提示「页面刷新后生成已中断，请重新生成。」。
- 画布列表在入口页 `/canvas`，支持新建画布、导入画布、导出选中、删除选中；卡片上会显示「X 个节点，Y 条连线」和更新时间。

## 生成状态与互通

- 生成中的节点显示「生成中...」；批量图片会显示「生成中 x/N」与进度条，全部完成显示「已完成 N/N」，失败显示红色图标与原因。
- 悬停节点可「重试（重新生成）」；提示词或参考图丢失时会提示「找不到提示词，无法重试」或「参考图片已丢失，无法继续重试」。
- **存资产**：悬停节点点「存资产（加入我的资产）」，成功后提示「已加入我的资产」。
- **用资产**：工具栏「我的资产」把资产插入为节点；左侧导航面板的「节点」「画布资产」两个页签可以搜索、按类型筛选并定位节点；图片节点还能用画布资产替换当前图。

## 快捷键一览

| 快捷键 | 作用 |
| --- | --- |
| 拖动空白处 | 平移画布 |
| 滚轮 / 缩放滑杆 | 缩放 |
| `Ctrl/Cmd` + 拖动 | 框选 |
| `Shift/Ctrl/Cmd` + 点击 | 追加选择 |
| `Ctrl/Cmd + A` | 全选 |
| `Ctrl/Cmd + C` / `V` | 复制 / 粘贴 |
| `Delete` / `Backspace` | 删除选中 |
| `Esc` | 取消选择并关闭浮层 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Y` | 重做 |
| `Ctrl/Cmd + Shift` + 拖动节点 | 发送到画布 Agent |
| 拖入图片或视频 | 上传为节点 |

顶栏用户菜单里的「画布快捷键」随时可以再打开这张表。

## 相关限制

- 音频仅 MP3 / WAV，单文件不超过 15MB。
- 合成视频最多 20 段视频节点；分镜镜头最多 100 个、分镜资产最多 300 个。
- 画布缩放范围 0.05～5；Agent 对话历史取最近 12 条。
