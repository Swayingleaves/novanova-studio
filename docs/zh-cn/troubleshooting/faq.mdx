# 常见问题

下面按主题整理常见现象、原因和处理方式。标注「管理员」的项需要管理员在系统配置里处理。

## 登录与账号

| 现象 | 原因与处理 |
| --- | --- |
| 提示「邮箱或密码错误」 | 核对邮箱与密码；确实忘记密码就用登录框里的「忘记密码」重置 |
| 提示「账号已被禁用」 | 账号被管理员停用，需要联系管理员重新启用 |
| 提示「账号已锁定，请 X 分钟后再试」 | 连续输错密码触发锁定，等待倒计时结束后再试 |
| 提示「登录已过期」或「登录已失效，请重新登录」 | 令牌过期或被服务端强制失效，重新登录即可 |
| 提示「操作过于频繁，请稍后再试」 | 触发了接口限流，稍等片刻再操作 |
| 登录页没有报错但一直进不去 | 检查 `NEXT_PUBLIC_SERVER_URL` 是否指向服务端、服务端是否已启动，见下面的自查手段 |
| 忘记密码 | 登录框点「忘记密码」，填注册邮箱后会收到一次性重置链接，链接有效期 15 分钟 |

## 模型与渠道（管理员）

| 现象 | 原因与处理 |
| --- | --- |
| 提示「请联系管理员配置默认生图模型 / 默认生视频模型」 | 还没有指定该类型的默认模型 |
| 提示「所选模型不可用，请联系管理员检查模型配置」 | 渠道或模型被停用、模型名不匹配，或渠道密钥失效 |
| 提示「服务端AI渠道未配置API Key」 | 渠道没有填密钥，或保存后未生效 |
| 提示「服务端任务系统暂不支持 X 调用格式」 | 该渠道的调用格式尚未适配，先换成已支持的格式 |
| 提示「未找到已选择的AI渠道」或「渠道 X 未配置模型」 | 任务引用了已删除或未配置模型的渠道 |
| 模型下拉是空的，或提示「请先到配置里添加渠道和模型」 | 渠道下没有标记对应能力（文本 / 图像 / 视频）的模型，需要在「我的模型」里标记能力并指定默认项 |
| 上游返回「内容审核未通过」「提示词包含敏感」 | 上游内容策略拦截，调整提示词或更换渠道 |

## 积分

| 现象 | 原因与处理 |
| --- | --- |
| 提示「积分不足，无法创建生成任务」 | 余额不够本次消耗，先兑换或购买积分 |
| 提示「没有配置发卡网站」 | 部署时未配置 `NEXT_PUBLIC_CREDIT_STORE_URL`，暂时无法自助购买，只能由管理员调整积分 |
| 卡密提示「请输入20位积分卡密」 | 卡密为 20 位，复制时不要带入多余字符，系统会自动去掉空格与横线 |
| 扣了积分但任务失败 | 到「积分记录」核对明细，并把时间点提供给管理员，管理员可在「积分明细」和「接口记录」里定位 |

## 上传与对象存储（管理员）

| 现象 | 原因与处理 |
| --- | --- |
| 提示「请联系管理员配置默认对象存储」或「完整配置默认对象存储」 | 没有配置默认对象存储，或配置不完整（缺必填项） |
| 提示「上传腾讯云COS失败」（OSS / Kodo 类似） | 凭证错误、存储桶不存在或没有写权限，确认后重新保存默认存储 |
| 头像上传失败 | 头像仅支持图片且不超过 2MB |
| 素材上传成功但打不开 | 存储桶访问权限或跨域设置问题，确认存储桶域名可以公网访问 |

## 生成任务失败

| 现象 | 原因与处理 |
| --- | --- |
| 提示「生成任务等待超时」 | 等待超过上限（图片默认 5 分钟、视频默认 15 分钟），常见原因是上游渠道慢或卡住，可以重试或换模型 |
| 提示「视频生成超时，请稍后重试」 | 上游渠道自身超时，稍后重试 |
| 提示「AI 返回内容无法解析，请重试」 | 模型返回了不完整或不符合预期的内容，重试即可 |
| 任务显示已取消 | 自己点了停止，或服务端重启中断了任务，重新提交 |
| 画布节点提示「页面刷新后生成已中断，请重新生成。」 | 刷新发生在任务 id 返回之前，重试该节点 |
| 重试提示「找不到提示词，无法重试」或「参考图片已丢失，无法继续重试」 | 节点缺少原始提示词或参考图，补齐后再生成 |
| 图片或视频页提示没有可用模型 | 先用管理员账号确认默认模型配置，见[系统配置](../using-studio/system-configuration) |

## 素材校验

| 现象 | 原因与处理 |
| --- | --- |
| 提示「参考音频仅支持 MP3、WAV」 | 换成 MP3 或 WAV |
| 提示「每段参考音频必须为2～15秒」/「参考音频总时长不能超过15秒」/「最多支持3段参考音频」 | 按提示裁剪时长与数量 |
| 提示「参考音频大小无效或超过15 MB」 | 压缩音频或换更短的片段 |
| 提示「音频输入仅支持已开启全能参考的视频模型」 | 换支持音频输入的模型，或把生成模式切到全能参考 |
| 参考图或参考视频被忽略 | 参考图单张不超过 30MB、最多 9 张；参考视频仅 MP4 / MOV、单条 2～15 秒、总时长不超过 15 秒、单个不超过 50MB、最多 3 个 |
| 提示「远程媒体文件超过100MB限制」 | 引用的外部媒体太大，先下载再上传为素材 |

## 自查手段

1. **服务端健康检查**：访问 `/api/v1/health`，正常返回 `{"code":200,"data":"OK"}`；本地默认 `http://127.0.0.1:18080/api/v1/health`。
2. **服务端日志**：项目根目录 `logs/current.log`（日志按 50MB 滚动、保留 180 天）。AI 调用会留下 `AI请求`、`AI响应 状态码`、`AI响应` 三行，模型相关的问题主要看这里。
3. **管理后台的「接口记录」**：管理员可以按接口、IP、用户与成功/错误筛选，查看状态码、耗时、请求体与错误内容，记录保留 30 天。反馈问题时提供大致时间点最有用。
4. **容器日志**：Docker 部署还可以用 `docker compose logs -f server`，同一份日志也会落在 `logs/server/`。
