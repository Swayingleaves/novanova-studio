# 🎉 Novanova Studio 1.0.3 更新说明

> 版本：**v1.0.3**　｜　发布日期：2026-11-21　｜　源码：[GitHub](https://github.com/Swayingleaves/novanova-studio)

**重点**：新增智能短剧工作台，从一句创意直接走到成片；图片下载加入「AI生成」标识设置；后台补齐收入统计、菜单管理、模型配置导入导出与导出视频开关；接入 NANA-API 官方中转站；首页作品墙改为无限滚动瀑布流。

## 🛠 修复和优化

- 修复图片下载在上游限速时会无限阻塞的问题：远程媒体读取加入截止时间（图片转存 150 秒、媒体登记 30 秒）；结果卡片先按本轮宽高比占位，加载完成不再顶动布局，NaN / Infinity 这类异常尺寸也一并兜住。
- 修复图片、视频任务完成时，流式回复被结果文案覆写导致的文字跳变。
- 修复后台「补齐封面」调用缺少请求体、点一次就报错的问题。
- 修复收益统计里赠送积分（productBonus）被截断成非负值的问题。
- 修复线上缺少短剧提示词模板环境变量、容器启动即失败的问题，docker-compose 与 `.env.example` 同步补全。
- 短剧的文本请求被中断时按现有退款策略释放积分；项目删除后，迟到的图片/视频结果连同对象存储一起清理，不留孤儿文件。
- 首页去掉静态回退样例，没有作品时不再展示内置图片；作品卡改为悬停播放按钮才播放，无封面视频不再预加载整段，卡片截图由 PNG 转 JPEG。
- 分镜提示词规则收紧：各时间段的动作与台词必须写进画面内容，按非等间距时间段规划镜头；单镜头默认 10–15 秒，最大镜头数上限从 50 提到 100。
- 模型列表改为自然排序，同名、同系列模型聚在一起，后台定价、模型选择与配置复制同步生效。
- 漫剧版本外观描述统一取资产描述，不再出现模型改写文案与实际生成对不上的情况。

## ✨ 新增功能

### 智能短剧工作台

一句话创意或粘贴故事即可开项目，按「制作方案 → 剧本 → 角色与场景 → 分镜 → 镜头 → 成片预览」六步推进，每步确认后才继续，确认本身不扣费；每步由不同身份的 Agent 应答（导演 / 编剧 / 角色设计师 / 分镜师 / 镜头师 / 剪辑师），可对话改稿、重做或撤销版本，回改已确认阶段会把后续阶段标记「需要更新」。画幅支持 9:16 / 16:9 / 1:1 / 3:4 / 4:3 / 21:9，整集图片和视频统一按该比例生成。

### 短剧媒体与成片

角色图、场景图、分镜静帧、从上一镜尾帧接续的 4×3 动作连续图、镜头视频，可一键补齐缺失项；成片合成与导出会先检查镜头视频是否齐备。

### 短剧体验

SSE 流式回复、思考中动效、媒体占位骨架屏与进度角标；镜头拆分草稿确认前提示将被覆盖的镜头与已生成媒体数量。

### 图片「AI生成」标识

页面常驻角标，首次下载图片弹一次设置，可选择把角标合成进文件像素或下载无水印原图；已接入图片结果卡、详情弹窗、素材库封面与预览、画布图片节点，个人中心可随时修改，设置按账号隔离，视频不加水印。

### 后台菜单管理

左侧导航支持开关与拖拽/上下移排序，桌面侧栏与移动端抽屉同步，系统管理项固定在管理员菜单末尾。

### 后台收入统计

积分明细拆成「消耗统计」「收入统计」两个页签，收入侧给出已支付订单、支付方式收入分布饼图与月度趋势折线。

### 模型配置导入导出

自定义模型可一键导出 JSON 带到另一实例导入，涵盖计费、能力、自定义请求体与尺寸映射；导入时校验格式与模型类型。

### 导出视频开关

后台可统一关闭漫剧视觉分镜板的「导出视频」，按钮随之隐藏并拦截提交。

### NANA-API 官方中转站

新增 `nana` 调用格式，默认地址 `api.novanovastudio.cn`，渠道列表带「官方」标记，新增模型时按模型名预置推荐能力；文本与图片走 OpenAI 兼容协议，视频按 Seedance / Wan / MiniMax 分流。

### 漫剧

镜头清单可一键批量生成当前镜头引用的资产图，并可从镜头清单跳回资产库定位高亮；清单支持刷新与生成中轮询；积分估算改为弹窗内实时计算；分镜预览与时间轴新增单镜头视频下载。

### 画布

助手回复改为直出并展开动效，不再逐字打字机；用户消息中的 @ 节点引用渲染成带类型图标的行内芯片；补上「思考中」扫光动效与减少动效适配。

### 首页

作品墙改为无限滚动瀑布流，按宽高比投放到最短列、追加去重、失败可单独重试、回到前台自动重置；卡片缩略图按 720 像素签发。

### 剧本

单集目标时长（30 秒 – 10 分钟）会换算成场次数与篇幅预算，分集与正文体量能和下游漫剧镜头拆分对齐。

## 关于 Novanova Studio

Novanova Studio 是一个 Agent 驱动的全流程开源创作平台，集 AI 图片生成、AI 视频生成、无限画布、自定义模型 API、AI 漫剧、AI 短剧、小说解析剧本、小说转短剧、3D 导演台、用户管理与积分管理于一体。
