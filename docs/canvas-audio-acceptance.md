# 画布音频验收

1. 在系统模型配置选择任意视频模型，按模型实际协议开启全能参考及“支持音频输入”，保存后重新打开确认；检查价格列表没有新增音频模式。未启用全能参考时不能开启音频输入。
2. 在画布工具栏或右键菜单创建音频节点，上传 MP3/WAV，也可直接拖入。检查标题、真实波形、总时长、上传反馈；空文件、损坏文件及超过 15 MB 的文件应明确报错。
3. 播放暂停、点击和拖动波形、键盘调整进度；检查节点不被误拖动，画布不误平移。播放另一节点后原节点停止，删除、替换音频或切换画布后不继续发声。
4. 在深浅主题分别检查文字、波形、红色进度线和选中边框；调整节点尺寸及画布缩放，控件应保持可操作。复制粘贴、撤销重做后音频仍可用，刷新后播放进度从零开始。
5. 导出 ZIP 后导入，检查音频播放和真实波形；连接到视频节点，刷新后参考素材名称、时长、顺序和存储标识仍可恢复。
6. 将音频连到全能参考视频节点，并从引用区再上传一段。检查同一素材不重复提交，编号与请求顺序一致；切换到不支持音频的模型或模式，应保留素材并显示错误。
   自定义模型请求示例可使用 `{{audioReferences}}` 占位符接收按引用顺序排列的音频 URL。
7. 使用每段 2～15 秒、最多 3 段、总计不超过 15 秒的音频实际生成。Evolink 同时提供图片或视频，确认请求包含 `audio_urls` 和 `@audio1`；MiniMax 确认 `audio_url` 项的角色为 `reference_audio`。检查生成失败后的重试仍携带音频。
8. 验证超过总时长、缺少存储标识、音频归属错误、类型不符或渠道适配器未实现音频协议时，服务端拒绝且不扣费；Evolink 仅有音频时也应拒绝。

实现阶段执行定向 Node 单元测试；未运行构建、语法检查、自动浏览器测试或会创建付费任务的真实渠道调用。Java 测试已补充，待用户在本地验证。
