# 微信 Native 支付接入

普通商户使用自己的商户号收款，采用 APIv3 和微信支付官方 Java SDK 0.2.17。使用 `RSAPublicKeyConfig` 加载微信支付公钥，用于应答和回调验签，不下载平台证书。商户 API 私钥与商户 API 证书序列号用于请求签名，微信支付公钥与公钥 ID 用于验签，两者不能互换。

## 商户准备

1. 商户号已开通 Native 支付权限，并与通过认证的 APPID 完成绑定。
2. 准备商户 API 私钥文件 `apiclient_key.pem`、商户 API 证书序列号、32 字节 APIv3 密钥。
3. 在商户平台「账户中心 → API安全 → 微信支付公钥」下载微信支付公钥文件及对应的 `PUB_KEY_ID_...` 公钥 ID。当前实现用于纯公钥模式；正在从平台证书灰度切换的商户，应先完成所有系统的双模式兼容改造，不可直接使用本实现承接灰度回调。
4. 配置可被微信访问的公网 HTTPS 回调地址，保留 `Wechatpay-*` 签名请求头和原始正文，不携带查询参数。

## 配置

在管理后台「支付配置」的微信支付页填写，不再使用环境变量或证书目录。真实私钥和密钥不得放入源码、前端目录或日志。私钥和 APIv3 密钥用 `APP_SECRET_KEY` 加密后写入 `platform_payment_settings`，接口只返回是否已设置；留空保存表示不修改。更换应用密钥后需要重新粘贴这两项。保存后当前实例立即生效，其他实例在 5 秒内刷新。

| 配置项 | 含义 |
| --- | --- |
| 启用微信支付 | 配置齐全后才能打开 |
| 应用标识 | 与收款商户号绑定的应用标识 |
| 商户号 | 普通商户号 |
| 商户 API 证书序列号 | 商户 API 证书序列号 |
| 商户 API 私钥 | `apiclient_key.pem` 的完整 PEM 内容 |
| APIv3 密钥 | 32 字节 APIv3 密钥 |
| 微信支付公钥 | 商户平台下载的微信支付公钥 PEM，不是商户 API 证书 |
| 微信支付公钥 ID | 与公钥对应的完整公钥 ID，包含 `PUB_KEY_ID_` 前缀，不能填商户证书序列号 |
| 支付通知地址 | 例如 `https://你的域名/api/v1/payment/wechat/notify`，不含查询参数 |

后台每 30 秒核对微信待支付订单；未启用微信支付时不扫描。缺少公钥或公钥 ID 时明确报配置错误。

如果商户平台原本已使用平台证书，下载公钥不会自动完成切换，应遵循官方切换指引。当前客户端只使用配置的微信支付公钥。

## 交易流程

- 前端继续调用 `POST /api/v1/payment/credit/createOrder`，传入商品标识和 `paymentMethod: "wechat"`。金额和到账积分以服务端商品快照为准。
- 返回的 `paymentUrl` 是微信 `code_url`，由 Ant Design `QRCode` 原样转换为二维码，不作为 iframe 页面或普通网页链接打开。用户须使用另一台设备的微信“扫一扫”，不支持长按或相册识别。
- 新订单号为 32 位随机标识，满足微信 6 至 32 位订单号要求；待支付订单继续支付时复用原订单号、金额和有效期。距离截止不足一分钟时拒绝重新下单，避免微信自动延长有效期。
- 回调入口为 `POST /api/v1/payment/wechat/notify`，不要求用户登录。先由官方 SDK 验签和解密，再核对商户号、APPID、交易类型、币种、平台订单金额和支付渠道。
- 回调和查单共用现有事务入账、渠道交易号唯一约束、订单条件更新、钱包行锁及首充赠送逻辑，重复通知不重复发放积分。已取消或关闭的订单若被渠道证实已收款，仍按原有规则入账。
- 在业务处理完成后返回 HTTP 204；验签或结算失败、处理超过 4 秒时返回 HTTP 500，让微信重试。此处选择持久化完成后确认接收，不提前确认未落库的通知。
- 启用微信支付后，后台每 30 秒按主键分页核对所有微信待支付订单，独立于浏览器运行；单笔失败保留待核对状态，不影响后续订单。
- 前端状态查询继续使用原接口及 Redis 节流。订单过期先查单：已支付则入账；未支付则先关闭渠道交易，再关闭本地订单。查单或关单结果不明时不把本地订单当作已取消或关闭。
- 官方客户端设置连接、读写和整次请求超时，并启用 SDK 主备域名重试。渠道请求和响应记录 Request-ID；鉴权头不写日志，用户 OpenID 脱敏。

## 验证范围

本地测试使用临时测试密钥、模拟 SDK 网络边界以及现有 JUnit/Mockito、WebFlux 和前端测试工具；不产生真实微信交易。真实商户签名验签、`/v3/security/echo`、实际扫码付款与公网回调仍须在安全配置完成后单独联调，不能以本地模拟通过替代。

当前接入范围为积分购买，不包含自动退款和每日微信账单下载对账。渠道收款与本地订单、积分流水可通过商户订单号和微信交易号关联核对。
