# ✍️ 剧本创作功能规格

## 🎯 产品定位

剧本创作是 NovaNova Studio 的故事与剧本工作台，目标是帮助用户把一句话创意逐步发展为结构完整、人物动机清晰、可持续修改的结构化剧本。

本模块只处理故事和剧本文本，不承担人物参考图、分镜、镜头提示词、配音、图片生成或视频生成。完成的剧本可以在同一个项目中继续进入漫剧创作。

| 用户状态 | 期望结果 |
| --- | --- |
| 只有一句话想法 | 获得故事方向、卖点、主要冲突和可确认的大纲 |
| 已有故事梗概 | 补全人物、世界观、结构、集数和每集剧情 |
| 已有剧本初稿 | 按集数和场次整理，并优化对白、节奏和冲突 |

## 🧭 用户主流程

```mermaid
flowchart LR
    A[新建剧本项目] --> B[输入创意或选择模板]
    B --> C[确认故事方向]
    C --> D[确认故事大纲]
    D --> E[完善人物与世界观]
    E --> F[规划集数和场次]
    F --> G[编写与优化剧本]
    G --> H[剧本分析与修改]
    H --> I[进入漫剧创作]
```

AI 助手必须按阶段推进，不得从一句话创意直接生成整部长剧本并替用户确认所有关键设定。

## 📚 P0 核心功能

### 1. 剧本项目库

项目库用于管理全部创作项目，至少展示：

- 项目名称、故事类型和一句话梗概。
- 当前集数、剧本完成度和最近修改时间。
- 当前阶段，例如构思中、大纲中、剧本编写中或已进入制作。
- 是否存在漫剧生产内容以及是否存在“需要更新”项。

用户从剧本创作菜单打开已经进入制作阶段的项目时，仍然编辑同一份共享剧本。

### 2. 故事概览

故事概览集中展示并编辑：

- 一句话创意和故事简介。
- 题材、类型、目标时长和目标集数。
- 主线剧情、主要冲突、主题和结局方向。
- 当前主要人物、世界观、集数和创作进度。

故事概览只呈现写作信息，不展示模型、图片尺寸或视频参数。

### 3. AI 灵感创作

用户可以从以下信息开始创作：

- 一句话创意。
- 故事主题和题材。
- 内容形式，例如漫剧、真人短剧、动画、广告、音乐视频或故事短片。
- 目标时长、集数和叙事风格。

AI 首轮输出应是可选择和可修改的故事方向，包括：

1. 故事核心与卖点。
2. 主线剧情和核心冲突。
3. 主要人物及其关系。
4. 故事走向、高潮和结局方向。
5. 建议的结构和集数规划。

用户确认故事方向后，AI 才继续生成人物、大纲或具体剧本。未确认的内容不得直接写入正式剧本。

### 4. 故事大纲

故事大纲支持以下组织方式：

- 一句话梗概和完整故事简介。
- 三幕结构、五幕结构或起承转合。
- 主线、支线和人物成长线。
- 集数大纲和每集关键事件。
- 冲突、悬念、反转、高潮和结局。
- 每集结尾悬念，用于推动用户继续观看下一集。

大纲中的关键事件应能关联到对应集数和场次，避免成为与正文无关的孤立文本。

### 5. 人物设定

人物文字设定至少包含：

- 姓名、身份、年龄、职业和在故事中的角色定位。
- 性格、价值观、目标、欲望、恐惧和人物动机。
- 外貌文字描述、习惯、语言特点和背景经历。
- 人物弧光，即人物在故事中的变化过程。
- 与其他人物的关系、关系阶段和冲突。

剧本创作只维护人物的叙事设定和外貌文字描述。人物参考图、三视图、表情、服装图片和声音属于漫剧创作。

### 6. 世界观与场景文字设定

世界观用于维护：

- 时代、地域、社会背景和整体基调。
- 世界规则、组织、势力、等级体系和特殊限制。
- 重要历史事件和故事发生前的背景。

场景文字设定用于维护：

- 地点名称、空间用途和叙事作用。
- 所处时间、天气、氛围和关键物件。
- 会在该地点发生的主要事件。

场景概念图、多角度场景图、光线参考图和天气视觉版本属于漫剧创作。

### 7. 集数与场次管理

集数管理至少包含：

- 集号、标题、剧情梗概、主要人物和主要场景。
- 关键事件、主要冲突、高潮和结尾悬念。
- 目标时长和当前完成状态。

每集由多个场次（Scene）组成。场次是发生在同一时间和地点的一段连续剧情，至少包含：

- 场次编号、地点、内景或外景、时间和出场人物。
- 场次目标、动作描述、对白、旁白和转场说明。
- 所属剧情事件以及与前后场次的关系。

用户可以调整集数和场次顺序。调整后只改变共享剧本结构，不自动生成镜头。

### 8. 结构化剧本编辑器

编辑器采用三部分工作区：

| 区域 | 作用 |
| --- | --- |
| 左侧结构 | 展示项目、集数和场次目录，支持定位和排序 |
| 中间正文 | 编辑场次标题、动作、对白、旁白和转场 |
| 右侧 AI 助手 | 对选中内容执行改写、扩写、优化和分析 |

编辑器需要区分动作、人物、对白、旁白等内容类型，避免把所有内容作为一段普通富文本处理。

### 9. 进入漫剧创作

- 项目内提供“进入漫剧创作”入口。
- 进入前展示剧本生产准备度，包括缺失的人物设定、场景设定和未完成场次。
- 准备度只用于提醒，不强制用户完成全部内容。
- 用户确认后进入同一项目的漫剧创作阶段，不创建副本。
- 进入操作本身不得自动生成分镜、图片或视频，也不得产生费用。

## ✨ P1 增强功能

### 1. AI 剧本优化

| 类别 | 能力 |
| --- | --- |
| 文本优化 | 润色、扩写、精简、改写、口语化和对白优化 |
| 剧情优化 | 增加冲突、悬念、反转、人物动机、情绪起伏和高潮 |
| 节奏优化 | 识别拖沓或跳跃的段落，并给出具体修改建议 |
| 风格转换 | 在短剧、漫剧、电影感、喜剧、悬疑等叙事表达之间转换 |

AI 修改默认先提供预览和修改理由。只有用户确认后才写入正文，并保留修改前版本。

### 2. 剧本分析

剧本分析以有依据的专业诊断为主，不以单一百分比评分作为默认结果。

分析范围包括：

- 剧情是否完整，前后事件是否存在断裂。
- 人物目标、动机和行为是否一致。
- 冲突、悬念、高潮和反转是否有充分铺垫。
- 场次是否重复、缺少作用或节奏失衡。
- 对白是否符合人物身份和当前情绪。
- 集数结尾是否具备继续观看的驱动力。

每条问题必须指向具体集数、场次或正文片段，并给出原因和修改建议。分析结果不得未经确认直接改写正文。

### 3. 人物关系图

- 基于 P0 的人物关系数据生成可视化关系图。
- 展示关系类型、关系方向、当前阶段和主要冲突。
- 支持按故事阶段查看关系变化，并允许用户手动调整。
- 关系图只呈现和编辑共享关系数据，不维护第二份独立关系记录。

### 4. 版本与修改对比

- 支持用户手动保存命名版本。
- AI 批量修改在应用前展示修改前后差异。
- 用户确认应用 AI 修改时保存修改前版本。
- 版本记录说明修改时间、修改人和修改摘要。
- 用户可以查看旧版本或恢复为旧版本；恢复动作需要二次确认。

### 5. 剧本模板

模板用于创建项目骨架，不直接生成无法解释的完整故事。首批可包含：

- 短剧：复仇、重生、悬疑、爱情、都市和穿越。
- 漫剧与动画：玄幻、仙侠、末世、科幻、武侠和校园。
- 叙事视频：广告、音乐视频、宣传片和故事短片。

模板可以预设推荐结构、集数范围和每集目标，但用户可以在创建时修改。

---

## 🚫 明确不属于剧本创作的能力

- 人物参考图、人物三视图、表情图和服装图片。
- 场景概念图、多角度场景图和道具图片。
- 将场次拆分为镜头。
- 分镜板、镜头清单和镜头提示词。
- 镜头景别、构图、运镜和生成参数。
- 配音、音效、背景音乐、图片和视频生成。
- 视觉连续性检查和成片编排。

这些能力统一由[漫剧创作](./漫剧创作功能规格.md)承接。

## ✅ 验收标准

1. 用户可以从一句话创意开始，分阶段确认故事方向、大纲、人物和剧本。
2. 项目内容能够按“项目 → 集数 → 场次”组织，并区分动作、对白和旁白。
3. 人物、人物关系、世界观和场景文字设定可以被剧本正文引用。
4. AI 优化和分析均指向具体内容，未经确认不得覆盖正文。
5. 用户可以查看修改差异和版本记录，并恢复指定版本。
6. 用户能够从当前项目进入漫剧创作，且项目标识和共享剧本数据保持不变。
7. 剧本创作页面不出现视觉资产、镜头、配音、图片或视频生成配置。
