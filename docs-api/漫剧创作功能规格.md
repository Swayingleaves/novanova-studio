# 🎬 漫剧创作功能规格

## 🎯 产品定位

漫剧创作是 NovaNova Studio 的叙事视频生产工作台。它继承剧本创作全部能力，并将共享剧本继续转化为人物、场景和道具视觉资产，拆分为可执行镜头，最终完成图片、声音和视频生产。

菜单名称保持“漫剧创作”，但工作台支持以下项目类型：

- 漫剧。
- 真人短剧。
- 动画。
- 广告故事。
- 音乐视频。
- 电影或故事短片。

## 🔗 与剧本创作的关系

漫剧创作不是第二套剧本系统，而是同一项目的下游制作阶段：

- 直接使用共享的故事、大纲、人物、人物关系、世界观、集数、场次和剧本正文。
- 可以在漫剧工作台中访问剧本编辑能力，修改结果同步回剧本创作。
- 视觉资产、镜头、分镜和生成结果作为下游数据关联到共享剧本，不反向复制剧本。
- 上游剧本变化后保留下游结果并标记“需要更新”，由用户决定更新范围。

漫剧创作菜单支持两个入口：

1. **新建完整项目**：从创意和剧本阶段开始，后续继续视觉生产。
2. **选择已有剧本继续**：打开已有项目并进入生产准备度检查，不创建项目副本。

用户可以回到任意上游阶段修改。系统必须保留已完成结果，并明确提示修改可能影响的下游内容。

## 🎥 P0 核心功能

### 1. 项目入口与生产准备度

从已有剧本进入时，系统检查但不自动修改以下内容：

- 是否存在故事梗概和可用剧本正文。
- 是否已按集数和场次组织。
- 场次是否具备地点、时间和出场人物。
- 主要人物和场景是否具备基本文字设定。
- 是否存在尚未确认的 AI 草稿。

检查结果分为“已具备”“建议补充”和“缺失”。用户可以继续制作，也可以返回完善剧本。继续制作不得自动触发分镜、图片或视频生成。

### 2. 项目生产设置

生产设置至少包含：

- 项目类型。
- 目标集数、单集目标时长和整体时长。
- 横竖屏方向与画面比例。
- 整体视觉风格和时代氛围。
- 目标平台或使用场景。

项目类型决定推荐流程和默认字段，但不得隐藏用户已经创建的数据。视觉风格是项目级默认值，单个场次或镜头可以明确覆盖。

### 3. 人物视觉资产

人物视觉资产继承剧本中的人物文字设定，并扩展：

- 主参考图、正面、侧面、背面、全身和半身参考。
- 常用表情和动作参考。
- 不同服装、年龄阶段或剧情状态版本。
- 声音、语速和语气偏好。
- 资产使用状态以及被哪些场次和镜头引用。

一个人物可以有多个明确命名的视觉版本。镜头必须记录实际引用的版本，不能只引用人物名称而丢失服装或状态信息。

### 4. 场景与道具视觉资产

场景视觉资产继承场景文字设定，并扩展：

- 场景概念图和主要视角参考。
- 不同时间、光线、天气和剧情状态版本。
- 空间布局、关键区域和可见道具。
- 被哪些场次和镜头引用。

道具视觉资产至少包含名称、用途、外观、所属人物或场景以及参考图。关键道具在不同镜头中应复用同一资产版本。

### 5. 场次与镜头自动拆分

场次（Scene）是剧本中的连续剧情段落；镜头（Shot）是一次连续拍摄或生成的最小画面单元。

系统根据以下信息生成镜头草稿：

- 来源集数、场次和剧本正文。
- 用户指定的拆分范围、节奏和重点；镜头数量可选，未指定时由模型按剧本内容自行判断。
- 项目视觉风格和目标时长。
- 人物、场景和道具资产。

自动拆分结果必须先作为可编辑草稿展示。用户确认后才成为正式镜头清单，不得直接覆盖已有镜头。

### 6. 分镜板与镜头清单

分镜板（Storyboard）面向创作者，以连续画面展示叙事节奏；镜头清单（Shot List）面向生产执行，以结构化字段描述每个镜头。

每个镜头至少包含：

| 字段 | 说明 |
| --- | --- |
| 镜号 | 镜头在当前场次中的顺序编号 |
| 来源 | 所属集数、场次和对应剧本片段 |
| 时长 | 预计镜头时长 |
| 景别 | 远景、全景、中景、近景或特写等画面范围 |
| 画面与构图 | 人物、场景、道具及其在画面中的关系 |
| 动作 | 镜头中发生的人物或物体动作 |
| 运镜 | 固定、推进、拉远、摇摄、跟拍等摄影机运动 |
| 光线与氛围 | 时间、天气、光线和情绪氛围 |
| 对白与旁白 | 当前镜头对应的对白或旁白 |
| 声音 | 环境音和关键音效 |
| 引用资产 | 当前镜头使用的人物、场景和道具版本 |
| 最终提示词 | 面向图片或视频生成的结构化描述 |
| 制作状态 | 草稿、待生成、生成中、已完成、失败或需要更新 |

用户可以新增、删除、复制和排序镜头。删除已存在生成结果的镜头时必须明确提示影响范围并二次确认。

### 7. 镜头提示词

镜头提示词由以下内容共同组成：

- 来源剧本片段。
- 当前镜头的画面、动作、构图、景别和运镜。
- 项目或镜头视觉风格。
- 当前引用的人物、场景和道具资产。
- 用户针对当前镜头补充的创作要求。

系统生成提示词后允许用户编辑。重新合成提示词不得自动覆盖用户手动修改的版本，必须先展示差异并由用户确认。

### 8. 图片与视频生成

图片生成包括：

- 人物、场景和道具参考图。
- 镜头分镜图。
- 镜头关键帧或候选画面。

视频生成包括：

- 使用镜头提示词与引用资产生成单镜头视频。
- 对失败镜头进行重试，并保留原失败原因和输入信息。
- 按镜头顺序预览，选择采用版本。
- 将采用的镜头视频送入现有合成视频能力进行编排。

批量生成前必须展示任务数量、生成范围和可能产生的费用，并由用户确认。

### 9. 无限画布联动

漫剧创作负责项目、阶段和结构化数据管理；无限画布负责灵活的视觉生成、对比和编排。

- 可以把剧本片段、人物、场景、道具、分镜和镜头发送到当前项目画布。
- 画布中的文本、图片、视频和音频节点可以作为镜头引用素材。
- 现有分镜脚本节点用于承载镜头与资产清单，不再建设第二套互不兼容的分镜节点。
- 从画布生成的结果保存回项目时，必须关联到对应资产或镜头。

### 10. 上游变更联动

当共享剧本或视觉资产变化时：

1. 计算受影响的集数、场次、镜头、分镜图、提示词和视频。
2. 保留全部已有内容和生成结果。
3. 将受影响内容标记为“需要更新”，并显示变化来源。
4. 允许用户选择单个镜头、当前场次、当前集或全部受影响内容。
5. 仅在用户确认后重新拆分、合成提示词或生成媒体。

“需要更新”表示来源已经变化，不表示当前结果不可继续使用。用户可以明确选择保留旧结果。

## 🔊 P1 增强功能

### 1. 对白、配音与声音

- 从共享剧本和镜头中提取对白与旁白。
- 为人物关联声音、语速、语气和情绪。
- 为镜头维护环境音、关键音效和背景音乐建议。
- 生成的声音素材与人物或镜头建立明确关联。
- 剧本对白变化后，将对应配音标记为“需要更新”。

### 2. 批量生产与进度管理

- 按镜头、场次或集数选择生成范围。
- 显示待生成、生成中、已完成、失败和需要更新数量。
- 失败重试只处理用户选中的任务，不重复生成已完成镜头。
- 生成前展示所选范围、模型设置和预计费用。

### 3. 视觉资产多版本

- 人物支持不同服装、年龄和剧情状态版本。
- 场景支持不同时间、天气、光线和破损状态版本。
- 镜头固定引用具体版本，切换版本时展示受影响镜头。
- 历史版本继续可查看，不因生成新版本而自动删除。

## 🧠 P2 后续能力

- 人物走位、视线关系和 180 度轴线等高级镜头调度检查。
- 面向复杂项目的镜头审批、审片意见和修改任务。
- 多人协作、评论、权限和制作责任分配。
- 更复杂的声音轨道、音乐节奏和成片时间线编排。

---

## 🚨 关键业务规则

1. 共享剧本始终只有一份，不在漫剧创作中复制。
2. 自动拆分、提示词合成和生成结果默认先形成草稿，不直接覆盖用户修改。
3. 上游变化只标记下游“需要更新”，不自动重生成。
4. 任何可能覆盖内容或产生费用的操作都需要用户明确确认。
5. 人物、场景、道具和镜头均需保留稳定关联，避免只依赖名称匹配。
6. 工作台优先复用现有无限画布、分镜、图片、视频、音频和合成能力。

## ✅ 验收标准

1. 用户可以新建完整项目，也可以选择已有剧本无复制地继续制作。
2. 漫剧工作台能够访问并修改共享故事、人物、世界观和剧本正文。
3. 用户可以建立人物、场景和道具视觉资产，并明确查看其引用关系。
4. 剧本场次可以生成可编辑的镜头草稿、分镜板和镜头清单。
5. 每个镜头包含画面、动作、景别、运镜、时长、对白、声音、资产和提示词信息。
6. 用户可以从镜头继续生成图片和视频，并在无限画布中组织结果。
7. 上游变化后，受影响内容被准确标记，旧结果继续保留，重新生成由用户确认。
8. 批量操作必须显示范围、任务数量和费用信息，不得静默执行。
9. 页面能够区分已有基础能力与尚未实现的规划能力。
