# 3D 导演台人工验收

## 功能接入

功能取自开源项目提交 `441bd9dc`，可从画布工具栏或空白区域右键菜单添加“3D 导演台”。场景、姿势、运动轨迹、机位和导出设置随画布文档保存。PNG 和 MP4 导出结果通过现有媒体上传接口保存，并回填为带来源连线的普通画布节点。

三维场景按需加载，内置人体模型及 CC0 授权保存在 `web/public/models/director-desk/`。视频使用浏览器本地编码，不依赖服务端逐帧导出接口，也不需要新增数据库迁移或服务端配置。

## 绘制与运动

1. 打开画布中的 3D 导演台，选中角色，进入“运动轨迹”。分别拖出圆形、直线、矩形和铅笔路径；确认时间轨道出现对应区间。
2. 使用钢笔点击多个锚点，按住拖出切线；用“完成路径”或“闭合路径”提交。修改锚点、切线坐标和高度，确认曲线同步变化。
3. 已有运动数据时重新绘制，分别选择替换与保留；按 Esc 取消未完成绘制，确认原工程不变。
4. 播放、暂停、逐帧、循环、拖动播放头和点击刻度；检查速度均匀、角色沿路径转身，以及关闭朝向后的效果。
5. 在视口或轨道聚焦后按空格播放、再次按空格暂停；长按只切换一次，暂停后继续播放应从当前时间接续，末尾播放应从头开始。输入框、下拉菜单、确认弹窗及导出过程中不触发播放快捷键，关闭导演台后不接管空格。
6. 确认中间不再显示深色地面块，导演视角保留网格。预览中心显示十字线，切换画幅、调整窗口和深浅主题时仍居中清晰；标记不妨碍选中与绘制，导出的 PNG 和视频不包含十字线。

## 多段轨迹回归验收

1. 保持默认 5 秒，给角色绘制矩形路径并选择跑步。将工程时长增加到 10 秒，确认播放头自动定位到第 5 秒，原轨迹和跑步片段仍为 0–5 秒。
2. 在第 5 秒绘制直线路径，再选择行走。时间轨道应同时显示 0–5 秒矩形、5–10 秒直线，以及对应的跑步、行走动作；播放在第 5 秒切换。
3. 点击两条轨迹或面板的片段下拉框，分别修改锚点、高度、朝向和时间区间。重绘时分别选择替换、取消；删除后半段，确认前半段轨迹和动作均保留。
4. 调整片段制造空档，确认角色在空档保持上一段终点；定位到空档绘制新路径，结束时间应止于下一段起点。尝试将片段时间改到重叠区间，应明确提示且保留原数据。
5. 给机位设置多段轨迹，检查固定目标、跟随角色、保存重开、PNG 及本地视频导出在第 5 秒前后与预览一致；导出仍只上传最终文件。

## 时间轨道直接编辑

1. 在轨迹条和姿势动作条上右键，点击“删除片段”，确认只删除所在对象的当前片段，不影响其他片段和轨道；也可聚焦片段后按 Delete 删除。
2. 拖动片段左右两端，确认条的边缘和时间提示实时变化，松开后同步更新右侧面板并自动保存。左右箭头可按帧调整聚焦的边缘，Shift 加箭头按秒调整。
3. 将左右边缘拖过相邻片段、工程边界或另一端，确认不会重叠、越界，且至少保留一帧；轨迹与姿势动作分别调整，机位轨迹也适用。
4. 拖动时按 Esc、切换窗口或取消指针操作，确认本次调整不写入工程。播放中开始编辑应暂停；导出中和对象锁定时禁止调整及右键删除。
5. 缩短后播放、保存重开及导出，检查均使用调整后的区间，其他片段内容保持不变。

## 人体与姿势

1. 确认蓝色人形具有头部、躯干、完整手臂、手掌、腿和脚；新增第二个角色，检查两者姿势互不影响。
2. 在“姿势”中依次选择 20 项预设并播放。检查循环动作持续运动，单次动作结束后保持姿态。
3. 暂停后用滑块和角度数值调整左右关节，再点击视口关节点使用旋转手柄；检查面板与模型同步。
4. 在不同时刻记录姿势关键帧，拖动时间轴检查过渡；叠加行走动作，确认头部与手臂微调仍有效。

## 场景对象删除

1. 选中人偶或道具，确认右侧“属性”页底部显示“删除当前对象”，与参数区分隔；切换到“姿势”或“运动轨迹”时不显示该按钮。点击后弹窗明确对象名称及其全部轨道范围，取消时工程不变；确认后其他对象保留。
2. 在左侧人偶或道具右侧点击小叉，弹窗应显示该对象名称；无须先选中对象。确认后只删除此对象及其轨迹、动作、姿势和关键帧，其他对象和当前选中项保持不变。
3. 选中机位或地面时不显示“删除当前对象”。锁定对象、播放、导出或素材上传过程中删除入口禁用；背景、素材和其他对象不受删除操作影响。
4. 删除被一个或多个机位跟随的对象，相关机位停止跟随，保留删除时目标点；检查已有目标点关键帧不会将视线拉回。保存重开和导出不出现失效对象引用。

## 机位、保存与导出

1. 给机位绘制路径，分别使用固定目标点与跟随角色。检查镜头位置、跟随偏移以及角色移动后的朝向。
2. 切换导演视角和机位视角。导演视角旋转、平移、缩放应不改变拍摄机位的数据。
3. 修改时长。已有内容超过新时长时应提示，先调整区间或删除当前关键帧后再缩短。
4. 保存并关闭重开，确认轨迹、动作、姿势关键帧与机位目标完整恢复。
5. 切换到机位视角，确认地面网格仍可见。导出 PNG 和视频，检查地面网格、人物、道具和背景与相同时间的机位预览一致，且不含编辑手柄、轨迹、关节点、机位辅助线及中心十字线。视频应先显示“本地编码”，再显示“正在保存云端”；网络面板中应只上传最终MP4，不出现逐帧上传、创建导出会话或合成任务轮询。
6. 切换深浅主题；重复打开、关闭导演台，并检查模型加载失败时的错误提示与重新加载入口。
7. 给当前拍摄机位绘制轨迹后，直接点击播放或按空格，无须手动切换视角，应自动进入“机位视角”并沿路径移动；暂停后保留当前机位画面。拖动播放头、点击刻度和逐帧定位也应使用对应时间的机位位置及跟随目标，和导出一致。
8. 播放中手动切回“导演视角”可观察机位运动；暂停后再次播放重新进入机位预览。点击轨迹片段或面板片段选择框进入导演视角编辑，确认绘制与导航仍可操作，且导演视角位置不会写入拍摄机位。

## 浏览器本地编码

视频使用 Mediabunny 和浏览器 WebCodecs 直接编码画布，输出固定30帧/秒、6Mbps的H.264 MP4。帧时间由工程时间轴确定，不取决于渲染或编码耗时。整段视频只调整一次导出尺寸，完成后恢复预览；最终文件通过现有媒体上传接口保存云端并回填画布。

需要支持H.264编码的浏览器，并使用HTTPS或localhost访问。不支持时明确报错，不回退到服务端传帧；编码失败时关闭编码器并恢复视口。
