# 分镜文字字体资源

前端与服务端各分发一份完全相同的字体文件。字体均按 SIL Open Font License 1.1 分发；每款字体的完整许可见同目录的 `*-OFL.txt`。下载日期：2026-09-24。Noto Sans SC、Noto Serif SC 和 Montserrat 从可变字体提取为常规字重 400 的静态实例，避免 Java2D 使用可变字体默认的较细字重。

| --- | --- | --- |

| NotoSerifSC.ttf | [Google Fonts / Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc) | NotoSerifSC-OFL.txt |
| LXGWWenKai.ttf | [霞鹜文楷 v1.522](https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522) | LXGWWenKai-OFL.txt |
| Inter.ttf | [Google Fonts / Inter](https://github.com/google/fonts/tree/main/ofl/inter) | Inter-OFL.txt |
